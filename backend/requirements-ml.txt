# ---- 本地 Embedding / Reranker ----
#
# ⚠️ RTX 50 系（Blackwell，算力 sm_120）必须使用 CUDA 12.8+ 的 torch 构建，
#    否则会报 "no kernel image is available for execution on the device"，
#    看起来像显卡故障，实际是 wheel 与架构不匹配。
#
#     硬件要求：NVIDIA 驱动 >= 570（RTX 50 系最低要求）
#
#     安装顺序很关键——必须先单独装 torch，再装其余依赖，
#     否则 pip 可能从 PyPI 拉到不匹配的版本：
#
#         pip install torch --index-url https://download.pytorch.org/whl/cu128
#         pip install -r requirements-ml.txt
#
#     安装后验证：
#         python -c "import torch;print(torch.__version__, torch.version.cuda, torch.cuda.get_device_capability())"
#         期望形如：2.x.x+cu128  12.8  (12, 0)
#
torch
sentence-transformers
