## 开封县绿健农作物种植农民专业合作社与众邦肥业（河南）有限公司种植、养殖回收合同纠纷案（high）

- 案号：（2014）开民初字第1129号｜法院：河南省开封县人民法院｜类型：种植、养殖回收合同（红薯种植协议及三方回收合同）
- 分类：订单农业购销｜文书：判决书｜金额：—
- **核心争议**：合作社依据2013年3月31日补充协议要求肥业公司支付有偿服务费、未收订单户补偿费及违约、名誉损失，公司以该协议非其签订、签字人无授权为由抗辩，拒绝承担责任。
- **裁判要旨**：法院认为2012年5月20日红薯种植协议加盖双方公章，系双方真实意思表示，对原、被告具有约束力；但根据三方签订的回收合同，被告的回收对象是种植户而不是原告，且被告已履行回收义务，种植户的损失是否存在应由种植户主张。2013年3月31日补充协议签字人为张国胜和王国法，无证据证明王国法的签字行为基于被告授权，该协议对被告不具有约束力，且签订于其他协议履行完毕之后。故原告各项诉请证据不足，判决驳回其全部诉讼请求，案件受理费4312元由原告承担。
- 违约条款：补充协议约定：众邦公司应给付绿健合作社劳动报酬每斤3分，具体数额按厂里实收账面给付；如未能收购或没有全部回收，给定单户造成损失按每亩6000斤、每斤3分的标准一次性补偿给绿健合作社，由绿健合作社负责对未收订单户逐一补偿，具体补偿面积按合同450亩减去已收亩数即为未收亩数。种植协议约定保底价每斤0.4元，市场价低于保底价按保底价回收，高于保底价时回收价格随行就市。
- **风险规则**：
  - [主体不适格] 2013年3月31日的补充协议由原告法定代表人张国胜与王国法签署，被告否认王国法系其代表并主张未授权，原告未能提交授权证明；且该协议签订于其他协议履行完毕之后。 → 法院认定：对王国法的签字行为被告不予认可，没有证据证明王国法的签字行为是基于被告的授权，因此该协议对被告不具有约束力。
    - 启示：补充协议、结算确认书等后续文件必须由合同相对方加盖公章或由持有效授权委托书的代表签署，并在签约时留存营业执照、法定代表人身份证明及授权文件，避免仅凭个人签字主张权利。
  - [主体不适格] 三方回收合同将被告（甲方）的回收义务对象约定为种植农户（乙方），原告为丙方负责指导，但原告以自己名义主张未收订单户的补偿款。 → 法院认定：根据三方所签合同，被告的回收对象是种植户而不是原告，且被告已履行了回收义务，因此种植户的损失是否存在应由种植户主张。
    - 启示：合作社若要以自己名义向回收方主张农户损失或代收补偿款，应在合同中明确约定债权归集、代为主张或债权转让条款并取得农户书面授权，否则将因诉讼主体不适格被驳回。
  - [拖欠款项] 原告依据补充协议中“劳动报酬每斤3分，具体数额按厂里实收账面给付”的约定主张有偿服务费54000元，但未提供可核对的实收账目证据。 → 法院认定：原告要求被告支付有偿服务费54000元证据不足，不予支持。
    - 启示：服务费、组织费、代收手续费等应按可核验的结算凭证计量，合同应约定过磅单、收购台账、对账单的出具与确认流程，并约定逾期不确认视为认可的规则，确保主张时有据可查。
  - [价格波动] 合同约定保底价每斤0.4元，实际市场价低于保底价时按保底价回收，市场价高于保底价时回收价格随行就市。 → 法院查明并确认：众邦公司负责回收产品，保底价每斤0.4元，实际市场价低于保底价时按保底价回收，市场价高于保底价时，回收价格随行就市。
    - 启示：采用“保底价+随行就市”定价的订单合同，须明确市场价的取值来源（如指定批发市场报价、权威机构发布价）、调价触发条件与书面确认程序，避免履约期内因价格口径不一产生争议。
- 原文摘录：根据三方所签合同，被告的回收对象是种植户而不是原告，且被告已履行了回收义务。因此，种植户的损失是否存在应由种植户主张。2013年3月31日的补充协议签字双方是张国胜和王国法，原告方对张国胜的签字行为予以认可，该协议对原告具有约束力。对王国法的签字行为被告不予认可，有没有证据证明王国法的签字行为是基于被告的授权，因此该协议对被告不具有约束力。

## 郴州神农大丰种业有限责任公司与胡述田种植、养殖回收合同纠纷一审民事判决书（high）

- 案号：（2015）湘排民初字第118号｜法院：萍乡市湘东区人民法院｜类型：种植回收合同（水稻杂交种子委托生产合同）
- 分类：订单农业购销｜文书：判决书｜金额：经双方结算实际种子款只有95000元；原告共计向被告汇款230000元，多支付135000元
- **核心争议**：种业公司依约向制种户支付预付款及前期费用共230000元，结算后种子款仅95000元，制种户既未按后续签订的两份种子生产合同继续制种冲抵多付的135000元，也未退还该款。
- **裁判要旨**：法院认为，原告郴州神农公司与被告胡述田之间的水稻杂交种子委托生产合同是双方真实意思表示，属于有效合同，原告依约及依被告要求共计汇款230000元，经结算实际种子款只有95000元，多支付135000元；双方后又签订两份种子委托生产合同，原告履行了合同义务不存在违约，被告并未通过履行合同义务来冲抵原告多支付的货款，也未及时退还该笔多收货款，属于违反合同约定，应将多收的135000元退还原告。因双方在合同中未约定违约金、欠条中也未约定利息，视为不支付利息，故对利息请求不予支持。
- **风险规则**：
  - [拖欠款项] 原告按合同约定或依被告要求分次支付生产预付款、制种前期费用共230000元，而结算后实际种子款仅95000元，被告多收135000元并出具欠条，却未退还。 → 法院认定被告胡述田未及时退还该笔多收的货款，其行为属于违反合同约定，应将多收的135000元退还给原告。
    - 启示：订单农业预付款应与交种/交货结算节点严格挂钩，超付部分应在合同中约定明确的退还期限、退还方式及逾期责任，避免仅凭欠条长期挂账。
  - [合同解除] 双方约定由被告继续替原告生产水稻种子以冲抵多付的135000元，并分别于2013年10月28日、2014年12月28日签订两份杂交水稻种子生产合同，但被告没有实际履行该两份合同。 → 法院认定，原告希望被告通过继续替原告生产水稻种子从而冲抵该笔多付的135000元，因此双方又陆续签订了两份种子委托生产合同，但被告胡述田并未通过履行合同义务来冲抵原告多支付的货款。
    - 启示：以新订单冲抵旧欠款时，应在合同中写明冲抵金额、履行期限、交种数量与质量标准，并约定新合同不履行时旧债务立即到期且可另行追索，防止债务被无限期递延。
  - [其他] 原告提交种子委托生产合同、种子款结算单、电子银行交易回单及被告出具的欠条等证据，被告经传票传唤拒不到庭、未答辩亦未举证。 → 法院认为该五组证据符合证据规则，形成了完整的证据链，均予采信；被告经传票传唤无正当理由拒不到庭参加诉讼，不影响本案的审理和事实认定，其不利后果自行承担。
    - 启示：订单农业履约中应留存书面合同、结算单、银行付款凭证，并要求对方对超付或多收款项出具书面欠条，形成完整证据链，以应对对方缺席或否认交易的情形。
- 原文摘录：本院认为，被告的行为属于违反合同约定，其应将多收的135000元退还给原告。故，原告要求被告偿还欠款的诉讼请求符合法律规定，本院予以支持。原告要求被告支付利息的诉讼请求，因原、被双方在合同中未约定违约金且在被告出具的欠条中也未约定利息，根据法律规定，视为不支付利息，故本院不予支持。

## 中源恒基（山东）现代农业开发有限公司与烟台市甲天下果蔬有限公司、海南王品农业科技开发有限公司种植、养殖回收合同纠纷民事一审民事判决书（high）

- 案号：（2021）鲁1524民初1232号｜法院：山东省东阿县人民法院｜类型：种植回收合同（《雪酥三号合作种植协议》）
- 分类：订单农业购销｜文书：判决书｜金额：货款共计126993元(1.8元/斤×57504斤+1.3元/斤×18066斤)；苗款175608元（195120棵×0.9元/棵）、中微肥1632元、“重茬100”14080元、生物菌肥49920元，共计241240元；香瓜亩产损失评估为6290元/亩，合计754800元
- **核心争议**：中源恒基按《雪酥三号合作种植协议》种植蜜瓜后，烟台甲天下未支付已采收果品货款且未继续收购，各方就货款、违约损失赔偿、违约金及苗款肥料款等互诉。
- **裁判要旨**：法院认定中源恒基与烟台甲天、烟台甲天下与海南王品签订的两份《雪酥三号合作种植协议》均系真实意思表示、合法有效。海南王品经烟台甲天下通知采收中源恒基香瓜、中源恒基基于该通知交付，均系履行各自合同义务，不构成私下交易；烟台甲天下未付货款，也未提供代销或推荐客户，致中源恒基无法另销而产生损失，应支付货款126993元并按评估的亩产损失754800元赔偿；约定按每亩2万元计算的违约金过高，以实际损失为限。基于合同相对性，海南王品不承担货款及违约责任；中源恒基应支付种苗款175608元、肥料及农药款65632元，无需支付技术人员工资；烟台甲天下主张的60万元违约金因证据不足不予支持。
- 违约条款：合同二第十条违约责任：1.乙方承诺本合同所生产的果品只供应给甲方，如有违反，甲方每次可向乙方收取违约金100万元（甲方允许的情况除外），情节严重的甲方有权同时解除本合同。2.如有一方违反本合同约定条款，情节严重或造成重大损失的，另一方可解除合同，并要求违约方支付违约金（违约金按每亩2万元计算）。合同一违约责任条款与合同二基本一致。
- **风险规则**：
  - [拖欠款项] 合同二约定“乙方提供发票，甲方验收合格并装车后付款”，且“结算时甲方先从应付给乙方的蜜瓜款中，按20%货款比例扣除供给乙方的种苗款”；实际“王品农业入库单”上均标注“款未付”。 → 法院认为，与中源恒基签订合同的系烟台甲天下，双方应按合同二约定全面履行义务；2020年6月3日至6月12日烟台甲天下共采购中源恒基一级香瓜28752kg、二级香瓜9033kg，共计货款126993元，“烟台甲天下应当按照合同二约定支付货款，但至今未付”，故对该货款诉求予以支持；因合同具有相对性，中源恒基要求海南王品支付货款未有合同依据，不予支持。
    - 启示：订单农业合同中应逐字写明付款义务主体、验收与装车节点、是否需先开票，并将种苗款、预付款的抵扣比例与扣完即止规则写清；交货环节使用双方签字并注明付款状态的入库单/过磅单作为结算凭据。
  - [质量争议] 海南王品提供“王品蜜瓜品质鉴定表”主张抽检香瓜大部分未达标而拒收，仅于2020年6月9日、6月10日、6月14日按最低标准每天抽检一次、每次10个瓜；合同则约定“非商品瓜甲方不负责收购”“果品达不到双方约定的品质要求，由乙方自行销售的，所销售给的客户需甲方推荐或经甲方同意的客户”。 → 法院认为，面对120亩的香瓜，每天抽检10个瓜的品质不能代表全部，特别是在各方对每天抽检的瓜的品质存有争议，中源恒基主张果品采摘下来至上市销售这段时间糖度仍在增加的情况下，烟台甲天下、海南王品更应审慎处理；即使认定香瓜品质不合格，烟台甲天下也未提供代销或者推荐客户，中源恒基基于“只供应给甲方”的约定无法将香瓜销往他处，期间产生大量损失，烟台甲天下应承担违约责任。
    - 启示：合同应约定可操作的分级抽检规则（抽样批次、抽样比例或数量、检测主体、糖度复检时点与复检方式、检测结果异议期），并对“不达标果品”明确约定收购方的代销义务、推荐客户义务及履行期限，避免收购方以一次少量抽检结论单方拒收而致种植方无处可销。
  - [其他] 合同约定“乙方承诺本合同所生产的果品只供应给甲方”；烟台甲天下主张海南王品与中源恒基违背约定私下交易，以微信聊天中海南王品向中源恒基索要银行卡号及入库单上无其签字为证。 → 法院认定，涉案香瓜最初系烟台甲天下通知海南王品来中源恒基的基地采收，海南王品基于烟台甲天下的通知采收、中源恒基基于对烟台甲天下的通知将香瓜交给海南王品采收，均是履行各自合同义务的表现，不应认定为私下联系、私下交易；海南王品索要银行卡号系为向张明勇支付其垫付的打包工人工资，款项直接支付给张明勇本人，双方之间未有其他汇款行为；烟台甲天下主张私下交易未提供充足证据，其要求支付违约金的诉求不予支持。
    - 启示：在“上游收购方—中间商—种植基地”的链条式订单中，应书面约定指定第三方上门收货、验收、代付费用的授权方式与通知留痕要求（如书面/可追溯的通知、指定收货人签认），并避免排他性条款与代销安排之间的冲突。
  - [其他] 合同二第十条第二款约定“如有一方违反本合同约定条款，情节严重或造成重大损失的……要求违约方支付违约金（违约金按每亩2万元计算）”，据此主张违约金240万元。 → 法院引用《民法典》第五百八十四条、第五百八十五条，认为中源恒基经鉴定确认香瓜损失为754800元（6290元/亩×120亩），双方约定的违约金2400000元（20000元×120亩）过高，违约责任以中源恒基香瓜损失754800元为限。
    - 启示：违约金或损失计算方法的约定应与合同标的规模、可预见损失相称，并预先约定损失认定方式（面积×亩产损失评估、第三方价格评估机构），以便违约发生时既有主张依据又不易被认定过高而调减。
  - [其他] 中源恒基与海南王品之间没有书面合同，但因海南王品实际采收、检测并出具入库单，中源恒基要求其共同支付货款、赔偿损失并承担违约金。 → 法院认为“因合同具有相对性”，海南王品基于烟台甲天下的通知采收中源恒基的香瓜、中源恒基基于对烟台甲天下的通知交付，均是履行各自合同义务的表现，中源恒基和海南王品并未存在直接的合同关系，要求海南王品支付货款未有合同依据；基于合同相对性，要求海南王品承担违约责任的诉求亦不予支持。

## 陈清华与王占民种植回收合同纠纷民事二审民事判决书（high）

- 案号：（2022）辽09民终103号｜法院：辽宁省阜新市中级人民法院｜类型：种植回收合同（辣椒种苗出售与辣椒回收）
- 分类：订单农业购销｜文书：判决书｜金额：“借款据”载明：王占民辣椒赔偿款50亩×3500元＝175000元；陈清华已给付王占民4万元，尚应赔偿135000元
- **核心争议**：出售的辣椒种苗品种错误致农户损失，双方达成每亩3500元的赔偿协议后，出卖方以赔偿额显失公平、农户未全部交付辣椒为由拒付剩余赔偿款。
- **裁判要旨**：二审认为本案案由应为种植回收合同纠纷，陈清华出售的种苗未附标签和使用说明、导致种苗错误并造成王占民损失，依《种子法》第四十一条第一款、第四十六条应承担赔偿责任。其出具的载明50亩×3500元＝175000元的“借款据”系双方就纠纷达成的赔偿事宜，陈清华提供的证据不足以证明出具时显失公平且存在重大误解，应作为赔偿依据；因双方对辣椒采摘、回收没有明确约定，达成赔偿事宜后采摘回收义务及风险由陈清华承担，其已付4万元应予扣除，故改判赔偿135000元。
- **风险规则**：
  - [质量争议] 陈清华向王占民出售50亩地的《越南野山辣1号》辣椒种苗，未附有标签和使用说明，王占民耕种后发现种苗品种错误 → 法院认定，根据《中华人民共和国种子法》第四十一条第一款、第四十六条，陈清华因其出售的种苗未附有标签和使用说明，导致出售的种苗错误，造成王占民损失，依法应当承担赔偿责任。
    - 启示：种苗、农资供应方应随货提供与实物相符的标签和使用说明，并在合同中明确品种名称、质量标准、验收与异议提出期限；采购方应留存购种凭证、标签、田间表现照片等证据，以便主张可得利益损失。
  - [其他] 双方对案涉辣椒的采摘、回收没有明确约定，仅在2020年8月26日达成“由陈清华赔偿每亩3500元、王占民将50亩辣椒给付陈清华”的赔偿协议并由陈清华出具“借款据” → 法院认定，因双方对案涉辣椒的采摘、回收没有明确约定，双方达成赔偿事宜后，陈清华负有对案涉辣椒采摘、回收的直接义务，何时、如何采摘和回收由陈清华决定，其应当承担由此引起的风险；陈清华没有充分证据证明王占民拒绝或阻挠其采摘、回收，或王占民将案涉辣椒私自处分，故应按照“借款据”内容进行赔偿。
    - 启示：订单农业合同须书面明确回收主体、回收时间与方式、质量标准、交付地点与计重方式，并约定采摘回收的组织方与风险负担；以单方出具的“借款据”等非典型凭证记载赔偿或结算内容的，应改由双方签署结算确认书，写明款项性质、数额与履行期限。
  - [拖欠款项] 陈清华出具“借款据”确认赔偿175000元，仅实际支付40000元，并抗辩该据系被逼迫出具、显失公平、存在重大误解 → 法院认定，该借款据系陈清华与王占民就本案所涉纠纷达成赔偿事宜，陈清华提供的证据不足以证明其出具“借款据”时显失公平且存在重大误解，理应作为赔偿损失的依据；陈清华已给付王占民4万元，该款应从赔偿款总额中扣除，陈清华还应赔偿135000元。
    - 启示：赔偿、结算类文书应避免使用“借款据”等名实不符的载体，须写明债务成因、金额、支付时间及是否含税；主张显失公平或重大误解的一方需承担举证责任，仅有他案回收合同价格、他人调解协议等间接证据不足以推翻已出具的自认性凭据。
  - [其他] 陈清华申请对《越南野山辣1号》及津红2号2020年每亩土地销售收入进行评估，评估机构以所需基础资料无法收集、评估对象市场价格难以询到为由退回委托 → 法院认定，因评估标的物已不存在，且委托后评估机构认为涉及的评估对象市场价格难以询到而退回，重新评估无意义，一审未准予重新评估并无不当。
    - 启示：涉农产品价格与产量损失的争议应事前在合同中约定损失计算方法（如参照当地农业农村部门统计数据、同期同区域同类作物均价），并在作物收获、销售环节及时固定测产、销售票据等证据，避免事后标的灭失导致无法评估。
- 原文摘录：因双方对案涉辣椒的采摘、回收没有明确约定，双方达成赔偿事宜后，陈清华负有对案涉辣椒采摘、回收的直接义务，何时、如何采摘和回收由陈清华决定，其应当承担由此引起的风险。陈清华没有充分证据证明在双方达成赔偿事宜后王占民拒绝或阻挠其采摘、回收，或王占民将案涉辣椒私自处分，故应按照陈清华向王占民出具的“借款据”内容进行赔偿。

- **风险规则**：
  - [质量争议] 合同约定甲方进行花叶质量验收，关键质量标准为大麻二酚（CBD）含量大于0.6%以上、四氢大麻酚（THC）含量小于0.3%、水分自然阴干；甲方有权委托第三方机构评估。甲方以CBD含量未达标为由拒收。 → 法院认为双方对花叶质量验收的约定内容具有明显不确定性，在质量发生争议时采取何种评估方式不能确定；鼎恒升药业公司仅以其自己出具的检测报告证明质量不符合约定标准，依据不足，应承担举证不能的不利后果。
    - 启示：订单农业质量条款应明确约定双方认可的第三方检测机构、取样时间与方法、检测批次、复检程序及检测费用承担，避免收货方以单方检测报告拒收。
  - [主体不适格] 二审中案外人提交委托协议，拟证明鼎恒升药业公司是受大兴安岭林格贝寒带生物科技股份有限公司委托种植大麻，义务应由该公司承担。 → 法院认为该证据与本案不具有关联性，不予确认；根据合同相对性原则，鼎恒升药业公司与富利合作社签订的合同仍应由鼎恒升药业公司履行。
    - 启示：签约前应核实交易对手是否受第三方委托、有无代理权限，并在合同中明确委托方、代理方与种植回收方的责任归属，防止一方以第三方委托为由拒绝履行。
  - [拖欠款项] 合同约定甲方按照约定标准和价格收购乙方产品，不得以任何理由拒收或压价收购；富利合作社收获干叶19.5吨后，鼎恒升药业公司以质量未达标为由不予回收付款。 → 法院认定富利合作社已按约种植、收割，鼎恒升药业公司亦应按合同约定履行回收及付款义务，判决其回收19.5吨大麻花叶并支付回收款780,000元。
    - 启示：合同应明确回收验收期限、付款期限、拒收的书面异议及证据要求，并约定逾期付款违约责任，避免收货方以质量异议长期拖欠回收款。
  - [质量争议] 鼎恒升药业公司以200元/亩向富利合作社出售450亩“汉麻1号”种子，并提供给种植户；种子为简易普通编织袋包装，未注明种子产地、重量等重要信息；合同要求花叶CBD含量大于0.6%。 → 法院查明“汉麻1号”并非药用大麻，其培育单位未表明种植后花叶CBD含量能达到0.6%以上，鼎恒升药业公司也未提交证据证实；且种子由其提供、种植受其指导，仅以自行检测报告主张质量不达标依据不足。
    - 启示：回收方提供种子或种苗时，应在合同中写明品种、用途、质量标准、标签标识及该品种能否达到约定回收指标的保证或风险分担，避免种源问题引发回收争议。
- 原文摘录：双方在合同中约定“由甲方进行花叶质量验收，并且甲方有权委托第三方机构对花叶质量进行评估”，可以看出双方对于花叶质量验收的约定内容具有明显的不确定性……富利合作社使用的是鼎恒升药业公司提供的种子，并且整个种植过程均是在鼎恒升药业公司的指导下进行的，鼎恒升药业公司仅以其自己出具的检测报告证明案涉大麻花叶的质量不符合约定标准的依据不足。

## 吉林省某农业发展有限公司与孙某种植回收合同纠纷一审民事判决书（high）

- 案号：（2024）吉7104民初154号｜法院：白城铁路运输法院｜类型：种植回收合同（金谷七号订单协议）
- 分类：订单农业购销｜文书：判决书｜金额：金谷7号种子款7500元（150亩×50元/亩）；协议约定保护价格为2.4元/斤，收购价格随行就市，保底不变
- **核心争议**：农业公司按订单协议向农户发放谷种后，农户是否应支付拖欠的7500元种子款，农户以公司未按约回收谷子、种款应在回收时抵扣为由抗辩。
- **裁判要旨**：法院认定双方签订的订单协议合法有效，原告已按约提供种子，被告接收种植并出具欠据，应履行给付义务。因协议和欠据均未载明付款时间，依《民法典》第五百一十条、第五百一十一条第四项，履行期限不明确的债权人可随时请求履行，协议履行期限已届满，判令被告给付种子款7500元。被告关于种款应在回收时按回收价款抵扣的主张无有效证据，不予支持；谷物回收中的质量争议不影响原告依欠据主张种子款。
- **风险规则**：
  - [质量争议] 合同约定质量要求：杂质、霉变、草籽不超3%，水分不超15%，不符合上述要求原告有权拒绝收购；被告证人出庭证实原告不回收谷子、构成违约 → 法院认为，被告抗辩主张合同没有履行系双方在谷物回收合同中因谷物质量产生的争议，并不影响本案中原告依合法有效的欠据向被告主张种子款的权利；证人马某、陈某证明的系被告所种植的谷物回收过程中产生的问题，与原告主张事项无关，不予采纳。
    - 启示：订单农业合同应把回收义务的触发条件、质量标准与验收程序写清，并约定质量争议时的处置与结算顺序，避免回收纠纷与种子（农资）款纠纷被拆成两个案件、农户既拿不到回收款又要先付种款。
  - [拖欠款项] 订单协议和欠据对种子款均未约定付款时间，也未约定付款方式 → 法院依《民法典》第五百一十条、第五百一十一条第四项认定，履行期限不明确的，债务人可以随时履行，债权人也可以随时请求履行，但应当给对方必要的准备时间；案涉协议约定的履行期限已届满，被告应负给付义务，原告要求给付种子款7500元的主张应予支持。
    - 启示：合同必须逐项写明农资款（种子、化肥、农药）的金额、支付时间、支付节点和支付方式；未约定付款期限时债权人虽可随时索要，但会给回款时点和诉讼举证留下极大不确定性与争议空间。
  - [主体不适格] 被告抗辩称其系与公司业务员郭某签订合同和欠据、公司未派人到场，主张合同相对方不是公司 → 法院认定，被告自己提供的案涉订单协议明确载明甲方为通榆县某农业发展有限公司并加盖公章，被告在乙方处签字认可；协议签订后由郭某代为发放种子，郭某亦出庭证实上述事项，被告主张不予支持。
    - 启示：由业务员、代理人或经纪人代为签约、发放农资时，合同抬头必须写明企业全称并加盖公章，交付凭证（欠据、收据）应载明系代公司履行并注明合同编号，防止农户以「与个人口头约定」为由否认企业的主体资格。
  - [其他] 被告主张种子款应在回收谷子时按回收价款予以抵扣（口头约定） → 法院认为，被告提出的种子款应在回收时按回收价款予以抵扣的主张未提供有效证据证明，本院不予支持。
    - 启示：凡涉及「以回收款抵扣农资款」「保底价与随行就市价并行」等结算安排的，必须在同一份合同中以书面条款明确抵扣顺序、结算时间和计价基准，口头承诺在诉讼中难以证明。
- 原文摘录：案涉协议和欠据上未载明付款时间，现协议约定的履行期限已届满，被告应负给付义务，原告要求被告给付种子款7500元的主张应予支持……另对被告抗辩主张合同没有履行系双方在谷物回收合同中因谷物质量产生的争议，并不影响本案中原告依合法有效的欠据向被告主张种子款的权利。

## 四川某某农业开发有限公司与中国某某财产保险股份有限公司成都市天府支公司保险纠纷一审民事判决书（high）

- 案号：（2024）川0191民初5276号｜法院：四川省成都高新技术产业开发区人民法院｜类型：中央财政水稻/玉米种植保险合同（政策性农业保险）
- 分类：农业保险｜文书：判决书｜金额：每亩保险金额700元；玉米投保面积合计1160.8亩、水稻投保面积合计524亩；某甲公司交纳保险费4716.44元（判决书原告诉称）
- **核心争议**：投保的水稻、玉米发生旱灾及病虫草鼠害后，保险公司是否应承担保险赔偿责任，以及保险标的面积、免责条款效力、赔偿金额如何确定。
- **裁判要旨**：法院认定保险合同成立生效；因保险公司未就免责条款尽到提示和明确说明义务，该免责条款不成为合同内容；旱灾、病虫草鼠害造成损失且损失率达20%以上属于保险事故，保险公司未及时定损应承担举证不能后果；按公估确认的实际种植面积、80%赔偿比例及保险单载明面积计算，判决赔偿保险金730380元。
- **风险规则**：
  - [自然灾害] 保险条款第五条约定暴雨、洪水、内涝、风灾、雹灾、冻灾、旱灾、地震及病虫草鼠害等直接造成保险玉米/水稻损失，且损失率达到20%以上（含）视为保险事故发生；投保后案涉水稻、玉米发生旱灾、病虫草鼠害。 → 法院认定：双方认可某甲公司的损失达到20%以上；旱灾是双方认可的事实，只是对旱灾的程度以及减产的程度不确定；对病虫草鼠害造成的减产损失作为保险责任并未限缩为“除因管理不善造成的病虫草鼠害损失”，因此因病虫草鼠害造成减产属于保险事故发生。
    - 启示：订单农业/农业保险合同应明确列明承保自然灾害与病虫草鼠害类型、损失率触发标准及定损方式；出险后及时报案并固定灾害、损失证据。
  - [其他] 保险公司以“自身管理不善”为由主张免责，并提交农业科技中心调研报告；投保单中保险人声明为打印文字，未加黑加粗，保险公司未证明送达及明确说明保险条款。 → 法院认为案涉保险条款属格式条款；《保险投保单》中保险人声明内容系打印文字，未采取加黑、加粗等方式标注；某某财保未举证证明就该保险条款向某甲公司进行了送达和明确说明，根据《民法典》第四百九十六条，该免责条款不成为合同的内容。农业科技中心调研报告属于专家咨询，不是鉴定意见，具有参考价值，但不能作为定案依据。
    - 启示：对免责条款须以显著方式提示并留存送达、明确说明的证据；投保单上的概括声明不能替代法定明确说明义务。
  - [质量争议] 保险公司出险后提出“宁单19”不属于经省级审定、不在四川推广区的玉米品种，主张不属于保险标的范围拒绝赔付；但其承保前已派员实地查勘种植的玉米和水稻。 → 法院认定：某某财保并无证据证明某甲公司种植的宁单19号不属于案涉玉米保险合同的保险标的范围；某某财保在承保前派员实地查勘了栽种的玉米和水稻，此时其能了解到种子的品种，知道或应当知道该品种是否符合保险标的范围；出险后又对品种进行限制，系不诚信的行为。
    - 启示：承保前应核验并书面固定品种审定、种植区域、种植规范等承保条件；投保人应保存种子合格证、经营备案表、承保前勘验记录，防止出险后以品种不符拒赔。
  - [其他] 投保时双方未现场测绘或查勘确定保险面积，出险后共同委托某乙公司公估，但《公估报告》实际为无人机航测面积，未评估损失；水稻实际644.32亩与投保524亩不符，玉米实际780.25亩与投保1160.8亩不符。 → 法院认为虽然某乙公司未对损失进行评估，但种植面积的确定是确定损失的前提；《公估报告》系根据某甲公司代表指示后无人机查勘，数据有事实依据，某乙公司和公估人员均具有相应资质，公估人员到庭解释，具有证明力；确认共计种植面积1424.57亩，其中玉米780.25亩、水稻644.32亩。
    - 启示：投保时应以现场测绘/查勘确定保险面积并写入保单；出险后共同委托有资质机构，委托事项应明确包含损失评估与面积测量。
  - [拖欠款项] 某甲公司报案后，某某财保委托查勘但一直未将种植损失确定并告知，未及时出具核定结果或定损，也未发出拒赔通知书。 → 法院认为根据《保险法》第二十三条及《农业保险条例》第十二条、第二十三条，保险人及时定损是法定义务；某某财保未及时出具核定结果或者定损，导致玉米和水稻的损失无法确认，应承担举证不能的法律后果。
    - 启示：保险人应在法定期限内核定并通知，拒赔应出具通知书并说明理由；被保险人应书面催告定损并保留报案、催告、沟通记录。
  - [其他] 保险条款第二十三条约定保险单载明保险面积小于可保面积时按比例赔偿，大于可保面积时仅赔实际面积并退还保费；案涉水稻保单面积小于实际面积，玉米保单面积大于实际面积。 → 法院认定：水稻实际种植面积属于无法区分保险标的范围，按保险单载明的保险面积与可保面积比例81.33%（524亩÷644.32亩）计算赔偿；玉米实际面积少于合同约定面积，保险人仅对实际种植面积核责核损，超过实际种植面积的投保部分退还相应保费。法院综合调研报告及证人证言，认可80%赔偿比例，确定玉米赔偿金436940元（780.25亩×700元/亩×80%）、水稻赔偿金293440元（524亩×700元/亩×80%），合计730380元。
    - 启示：保单载明面积应与实际可保面积一致；合同应明确面积误差、超保/不足额投保的赔付计算规则及保费退还机制。
- 原文摘录：某某财保未举证证明就该保险条款向某甲公司进行了送达和明确说明。根据《中华人民共和国民法典》第四百九十六条……该免责条款不成为合同的内容。由于某某财保未及时出具核定结果或者定损，导致玉米和水稻的损失无法确认，其应该承担举证不能的法律后果。

## 新疆某某农业发展有限公司与王某某种植回收合同纠纷二审民事判决书（high）

- 分类：订单农业购销｜文书：判决书｜金额：某某公司以每公斤28元的价格收购王某某合格种子；约定繁育面积30亩，每亩交种不少于150公斤；王某某实际收获豇豆种子5680公斤，以10元／公斤出售获价款58,720元，部分发霉变质种子以打包价1,920元售出。

- **裁判要旨**：法院认定双方签订的《豇豆繁种联保合同》系真实意思表示、合法有效，双方系种植回收合同关系（一审认定案由不当，二审予以纠正）；某某公司作为先履行义务一方未按约定期限回收案涉种子，存在违约行为，且其主张的实际损失未提供证据证实，故对其按合同产值1.5倍主张的189,000元制种损失不予支持，一审根据公平原则和诚信原则，兼顾合同履行情况、当事人过错程度及预期利益，酌情确定王某某承担制种损失12,000元并无明显不当，二审驳回上诉、维持原判。
- 违约条款：王某某交种数量不少于合同约定的数量，少于约定数量部分，王某某每公斤按合同约定单价的1.5倍向某某公司赔偿；付款方式为收种时种子款在净度、发芽率、纯度、鉴定合格后12月底付清；某某公司向王某某提供的原种款、架材款、定金、借款，在当年种子收购时全部扣清。
- **风险规则**：
  - [拖欠款项] 合同约定了交种期限（2023年9月1日前每亩交种100公斤以上，2023年11月1日前将剩余种子全部交清），但双方未书面约定交种地点及交种方式；交种期限届满后收购方以需等上家款项到位为由未收种。 → 法院认定，交种期限届满后，某某公司一直未能及时收种也未向王某某提供具体交种地点，某某公司作为先履行义务一方未按约定期限回收案涉种子，存在违约行为。
    - 启示：订单农业合同必须明确约定交种（交货）的具体地点、方式、联系人、验收流程与时限，并约定收购方逾期不收购时的催告程序与救济措施，避免因约定不明导致农户无法交付、收购方反以农户未交付主张违约。
  - [擅自处分] 合同约定王某某不得将豇豆种子售予合同外第三方，但收购方逾期不收种、种子存在发霉变质，王某某于2023年11月5日将5680公斤种子以10元／公斤出售给他人。 → 法院认定，王某某在多次联系某某公司未果、案涉豇豆种子亦存在发霉变质、无力保存的情况下将种子出售给他人，双方均未按照合同履行义务，故根据公平原则和诚信原则兼顾合同履行情况、当事人过错程度及预期利益等综合因素，酌情确定王某某应承担的制种损失为12,000元。
    - 启示：排他性销售（不得外卖）条款应配套设置例外与处置机制，如收购方逾期未收种达到一定期限即视为同意农户自行处置，并约定处置价款分配、损失计算方式，以减少双方均违约时的争议。
  - [质量争议] 合同约定种子款在净度、发芽率、纯度、鉴定合格后于12月底付清，但未约定交种前的保管责任人；收获后种子出现发霉变质。 → 法院查明并经双方确认，双方没有约定具体的交种地点和交种方式，亦未约定案涉种子在收获后交种前的保管人；并认定王某某是在案涉豇豆种子存在发霉变质、无力保存的情况下出售。
    - 启示：合同应明确质量检验的时间、地点、检验主体、异议期限，以及种子（农产品）收获后至交种前的保管责任主体、保管费用和品质劣变风险的承担方，防止因迟延交付导致的品质争议转化为损失分担争议。
  - [其他] 收购方按合同约定产值1.5倍主张制种损失189,000元，但仅主张未举证；并主张已告知农户将种子拉运到米东区蒋家湾存放、技术人员随时查看等事实亦未举证。 → 法院认为，某某公司对其实际损失未提供证据加以证实，其对技术人员查看、王某某不配合精选验收、已告知存放地点等主张的事实亦未提交相应证据加以证实，故对上述主张不予采信；对其189,000元制种损失请求不予支持，仅酌情支持12,000元。
    - 启示：违约金或损失赔偿条款不宜仅以合同产值倍数虚高约定，应约定与实际投入挂钩的损失计算与举证方式，并保存原种款、架材款、人工、农资等成本凭证及田间服务、催收、调解等过程记录，否则高额索赔难以获法院支持。
  - [其他] 2023年11月6日收购方向王某某转账20,000元并备注“豇豆种子预付款”，王某某抗辩该款系收购方使用其3.8亩土地种植实验田的费用，双方对款项性质存在争议。 → 一审法院认为，合同约定某某公司提供的原种款、架材款、定金、借款在当年种子收购时全部扣清，王某某已将案涉种子出售他人，故对某某公司要求返还20,000元预付款的诉讼请求予以支持；对王某某关于该款系实验田费用的抗辩不予采信，王某某可另案主张。
    - 启示：预付款、定金、原种款、架材款等各类款项应在合同中逐项列明金额、性质、支付条件与扣回方式，转账备注应与合同一致并由对方书面确认，避免款项性质不清引发返还与抵扣争议。
- 原文摘录：某某公司作为先履行义务一方未按约定期限回收案涉种子，存在违约行为。对其要求王某某承担制种损失189,000元的主张，一审法院根据公平原则和诚信原则兼顾合同的履行情况、当事人的过错程度以及预期利益等综合因素，酌情确定王某某应承担的制种损失为12,000元并无明显不当。

## 某糖业有限公司与董某某农机作业服务合同纠纷民事二审民事判决书（high）

- 案号：（2024）新27民终184号｜法院：新疆维吾尔自治区博尔塔拉蒙古自治州中级人民法院｜类型：农机作业服务合同（背景为甜菜购销合同）
- 分类：农机作业｜文书：判决书｜金额：董某某主张农机作业费173,233.8元；《甜菜购销合同》约定甲方收购甜菜到厂价（保底价）550元／吨
- **核心争议**：收购方某糖业有限公司出具承诺并安排农机户为种植户采收甜菜后，农机作业费应由收购方还是由种植户承担。
- **裁判要旨**：二审驳回上诉、维持原判。法院认为，某糖业有限公司通过种植前订购方式与农户签订《甜菜购销合同》，并对农户播种、田间管理、收购全过程实施监督检查和提供技术服务指导；其在种植户不能及时采收时联系农机户董某某采收，属维护自身利益的行为，董某某基于该公司出具的《关于机收周某某砂石甜菜地的承诺》作业并将甜菜交付该公司，作业费亦由该公司工作人员田某某出具明细表确认，故该公司应依其承诺支付农机作业费；其与周某某之间《甜菜购销合同》的约定不影响董某某的请求，追加第三人的上诉理由不成立。
- **风险规则**：
  - [拖欠款项] 收购方某糖业有限公司出具《关于机收周某某砂石甜菜地的承诺》，载明“由我公司原料车间相关人员安排进入周某某甜菜地采收机组，采收费结算由我公司负责”，事后又以“不是农机作业费承担主体、仅系帮助协调”为由拒付剩余款项。 → 法院认定：某糖业有限公司作为甜菜收购方，在种植户不能及时采收订购甜菜情况下联系农机户董某某对周某某的甜菜地进行采收，属维护某糖业有限公司利益行为，董某某基于该公司出具的承诺采收并将甜菜交付该公司，故某糖业有限公司应当依照其承诺向董某某支付农机作业费。
    - 启示：收购方为保障订单农产品及时采收而向第三方（农机户、劳务队等）书面承诺“费用由我方结算”时，该承诺构成独立的付款义务来源；若要限定自身责任，应写明仅为代为转付、以种植户结算款到位为付款条件，并明确未到位时的处理方式，而不是笼统承诺“结算由我公司负责”。
  - [其他] 双方未针对农机作业事宜签订任何书面合同，结算依据仅为收购方出具的承诺函及其原料车间工作人员田某某签字确认的《农机作业费未收回明细表12.04》。 → 一审、二审法院均以某糖业有限公司工作人员田某某出具的明细表确认董某某未付农机作业费173,233.8元，并结合该公司出具的承诺，认定支付义务由该公司承担（该公司认可田某某系其公司原料车间工作人员）。
    - 启示：没有书面合同的作业服务，法院会以收购方盖章承诺函、其员工签字确认的对账明细来认定债务；企业在订单农业履约中应管控现场人员与作业方的对账、签认权限，防止未经授权的签认形成付款义务，同时作业方应争取取得加盖公章的确认文件。
  - [其他] 收购方上诉主张一审遗漏当事人，应追加种植户周某某为第三人，并以《甜菜购销合同》约定“甜菜采收、拉运义务及费用均由周某某承担”抗辩付款责任。 → 法院认为，某糖业有限公司主张追加案外人周某某，应提供证据证实周某某与董某某之间具有采收案涉甜菜的农机作业费约定，该公司未提供证据证实其主张，且该公司与周某某之间《甜菜购销合同》的约定不影响本案董某某农机作业费用的主张，故其上诉理由不能成立。
    - 启示：订单农业中“种植户自行负责采收拉运及费用”的约定只在购销合同双方之间有效，不能对抗收购方直接对接并作出承诺的农机/劳务第三方；若确需由种植户付费，应由种植户与作业方另行签订作业合同，收购方仅做居间协调并书面声明不承担付款责任。
- 原文摘录：某糖业有限公司通过种植前订购方式与农户签订《甜菜购销合同》，并对农户播种、田间管理、收购的全过程实施监督检查和提供技术服务指导，某糖业有限公司作为甜菜收购方，在种植户不能及时采收订购甜菜情况下，为及时采收种植户的甜菜，联系农机户董某某对案外人周某某的甜菜地进行采收，属维护某糖业有限公司利益行为，董某某基于某糖业有限公司为其出具的《关于机收周某某砂石甜菜地的承诺》……故某糖业有限公司应当依照其承诺向董某某支付农机作业费。

## 张某某与某某农产品有限公司买卖合同纠纷二审判决书（high）

- 案号：（2024）辽07民终448号｜法院：辽宁省锦州市中级人民法院｜类型：土豆收购合同（种植回收/买卖）
- 分类：订单农业购销｜文书：判决书｜金额：合同约定种植面积200亩，收购价格：一级品0.88元/斤（干物质18.0%以上）、二级品0.75元/斤（17.5%-17.99%）、三级品0.62元/斤（17.0%-17.49%）；张某某将土豆以1.315元/斤出售给案外人刘金良，取得货款1,013,726元。
- **核心争议**：种植户未经收购方允许将收获的土豆全部出售给案外人，收购方请求解除合同并按每亩1000元赔偿损失，种植户则主张合同系显失公平的格式条款应属无效、违约金计算基数应为实测160亩而非180亩。
- **裁判要旨**：二审认为案涉合同书系收购方事先拟定、未证明与种植户逐条协商，应视为格式条款，但不属于民法典第四百九十七条规定的无效或第四百九十六条不成为合同内容的情形，且双方2022年已签订内容基本一致的合同并履行完毕，种植户对主要条款明知，合同有效。种植户未经允许将成熟土豆出售他人，属合同约定的违约行为并致合同目的不能实现，构成根本违约，依民法典第五百六十三条支持解除合同、依第五百八十五条支持按约定赔偿。因合同中1000元/亩的违约条款约定不明确产生两种解释，依民法典第四百九十八条应作不利于提供格式条款一方的解释，按实测160亩计算，改判赔偿160,000元。
- 违约条款：合同六、乙方责任第3项：“乙方不经甲方允许，私自出售合同内合格的产品，按照1000元/亩赔偿给甲方经济损失。”
- **风险规则**：
  - [擅自处分] 合同约定“乙方不经甲方允许，私自出售合同内合格的产品，按照1000元/亩赔偿给甲方经济损失”，而种植户在土豆成熟后以1.315元/斤全部出售给案外人，致合同无法继续履行。 → 法院认定上诉人未经被上诉人允许将案涉成熟土豆出售给他人，属于合同约定的违约行为，已导致合同目的不能实现，故支持解除合同；并依民法典第五百八十五条第一款按合同约定的1000元/亩计算损失赔偿，认定构成根本违约，应承担相应违约责任。
    - 启示：订单收购合同应明确约定种植户的专供/定向交付义务与“私自外售”的违约后果，同时把违约金的计算基数（按合同面积、供种面积还是实测面积）、面积确认方式和确认时点写清楚，避免事后就基数产生歧义。
  - [其他] 合同约定“私自出售合同内合格的产品”按1000元/亩赔偿，但对按合同载明的200亩、供种180亩还是实测160亩计算并未明确，双方对该条款出现两种解释。 → 法院认为因合同书中该违约条款对此约定并不明确，导致双方当事人对该条款出现了两种不同的解释，依民法典第四百九十八条应当作出不利于提供格式条款一方的解释，即应按照160亩计算违约金数额为16万元。
    - 启示：违约金条款不得留有解释空间：应写明计算公式与计量依据（如“以甲方书面确认的实测面积×1000元/亩”），并配套签署面积确认单，否则格式条款歧义将按不利于条款提供方的方向解释。
  - [质量争议] 合同只约定收购“合格产品”，标准为长度7.5公分以上、干物质17.0%以上，按干物质含量分级定价，交货地点为哈尔滨某某公司院内，由第三方检测定级；种植户主张不合格的土豆不收购且无任何补偿。 → 法院认定案涉合同书虽系被上诉人事先拟定、应视为格式条款，但合同约定的各项条款并不存在法律规定的无效以及不成为合同内容的情形；又因上诉人2022年已签订与本案内容基本一致的合同并履行完毕，对双方合作模式及主要条款明知，故认定合同有效，上诉人主张合同条款无效缺乏事实和法律依据。
    - 启示：分级定价与第三方验收条款应明确可操作的质量指标、取样与检测主体、检测费用承担、复检与异议程序，以及不合格品的处理方式（拒收、降级或补偿），避免“合格”标准单方掌握引发显失公平争议。
  - [价格波动] 合同约定一级品0.88元/斤，而当年市场价约1.315元/斤，种植户以市场价格出售给案外人，并主张合同价格远低于市场价、显失公平、格式条款无效。 → 法院未采纳“合同价格低于市场价即显失公平、条款无效”的抗辩，仍认定合同有效，种植户以市场价自行出售构成违约，应按合同约定承担赔偿责任。
    - 启示：订单农业合同中应设置价格调整/随行就市或保底价加浮动的机制，并明确价格调整的触发条件与协商程序，减少农户在市场价格高于合同价时的违约诱因。
  - [合同解除] 收购方起诉后变更请求为解除合同，种植户主张解除未经通知、以假想事实起诉，不符合起诉条件。 → 法院依民法典第五百六十三条第四项认定，一方有其他违约行为致使不能实现合同目的的，当事人可以解除合同，种植户私自出售土豆已致合同目的不能实现，故原审判决解除合同并无不当，二审予以维持。
    - 启示：合同中应明确约定解除条件与解除权行使方式（书面通知的送达地址、生效时点），并保留违约事实的证据，以便在根本违约发生时顺利解除并主张损失。
- 原文摘录：案涉合同书被上诉人事先拟定，被上诉人未提交充分证据证明签订合同时与上诉人就每一项条款进行了协商，故应视为格式条款。但是，案涉合同书约定的各项条款并不存在前述法律规定的无效以及不成为合同内容的情形……因合同书中该违约条款对此约定并不明确，导致双方当事人对该条款出现了两种不同的解释。根据前述法律规定，应当作出不利于被上诉人的解释，即应按照160亩计算违约金数额为16万元。

## 杨某与包某种植回收合同纠纷二审民事判决书（high）

- 案号：（2025）新22民终794号｜法院：新疆维吾尔自治区哈密市中级人民法院｜类型：种植回收合同（辣椒订单合作种植及收购合同）
- 分类：订单农业购销｜文书：判决书｜金额：种植面积60亩，每亩株数3500-4000，收购价格12元每公斤；包某已支付97,500元；判决包某支付辣椒苗款23,750元
- **核心争议**：包某实际种植辣椒的亩数应认定为合同约定的60亩还是50亩，据此辣椒苗款及利息如何计算。
- **裁判要旨**：二审法院认为，虽合同载明种植面积60亩，但结合包某2022年4月20日微信转账10,000元、17,500元及杨某2022年4月23日出具收据确认收到50亩地承包费等履行行为，可认定双方协商一致变更合同内容，实际种植面积由60亩变更为50亩，一审按50亩计算苗款适当，予以维持。关于利息，合同未约定付款时间，杨某未提交催款或对账结算证据，结合其怠于主张权利，一审自起诉之日计算利息并无不当，故驳回上诉、维持原判。
- **风险规则**：
  - [拖欠款项] 合同仅约定“剩余48,000元栽苗时付清”，但法院认定双方对支付辣椒苗的时间及逾期付款利息均未明确约定，杨某亦未提交催款或对账、结算证据，2022年发生的合同关系至2025年才起诉。 → 法院认为，从合同约定看并未约定付款时间，从杨某举证责任看其未提交催促包某付款或双方进行对账、结算的证据，结合杨某怠于主张权利，一审自起诉之日计算利息并无不当。
    - 启示：订单农业合同应明确约定各笔款项的付款时间节点（如栽苗前、栽苗时、采收后）、逾期付款利息标准及定期对账结算机制，并在对方逾期后及时书面催告并留存证据，避免利息起算点因约定不明而推后至起诉之日。
  - [其他] 合同明确约定种植面积60亩，但履行中包某按50亩支付土地承包费，杨某接收款项并出具“包某地租50亩×1550元=77,500元”的收据，双方微信语音亦提及“50亩地的”。 → 法院依据《中华人民共和国民法典》第五百四十三条，认定当事人协商一致可以变更合同，变更后的内容可替代原合同内容；结合后续转账及收据，可以认定双方通过履行行为变更了合同约定内容，即包某实际种植面积由60亩变更为50亩。
    - 启示：合同履行中如需调整种植面积、收购数量或价款，应签订书面补充协议并明确变更后的亩数、单价与结算方式，避免以收款、开票等默示行为被认定为变更合同而使供方丧失按原合同主张的权利。
  - [其他] 杨某主张按合同约定的60亩交付辣椒苗，但除合同、运输凭证外未提供受方签收确认的交付数量凭证，且对50亩收据的出具原因未作出合理解释。 → 法院指出，杨某未提供充分的证据证实其向包某提供了60亩土地的辣椒苗，依据《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第九十条，应由负有举证证明责任的杨某承担举证不能的不利后果；杨某对二审拟组织的现场测量表示不同意。
    - 启示：种苗、农资交付应制作经双方签字（或微信确认）的交付单，载明亩数、株数、单价、金额与交付日期，并妥善保存对方对面积、数量的书面确认，避免仅凭合同约定主张交付数量而承担举证不能的后果。
- 原文摘录：从后续履行情况来看，2022年4月20日，包某通过微信向杨某分别转账10,000元、17,500元，杨某接收前述款项并认可50亩地的承包费已经结清。结合2022年4月23日杨某出具收据，认可收到50亩地承包费的事实，可以认定双方通过履行行为变更了合同约定内容，即包某实际种植面积由60亩变更为50亩。

    - 启示：订单农业合同中应事先约定产量/品质争议的定损方法、取样规则、鉴定或第三方检测机构及举证责任分配，并写明多次查勘、一次定损的时点，避免事后“无法鉴定”时权责不清。

    - 启示：订单农业中涉及合作社、农户、收购方多方的，应在合同中逐一列明实际种养户身份，并保证投保单、保险凭证/订单、收款人名称一致，避免因主体不清引发资格争议。
- 原文摘录：人保公司履行了赴现场查勘定损的义务，但查勘后并未向程宗利出具现场查勘报告，亦未向程宗利出具拒绝赔偿通知书。人保公司未按约定履行义务的行为致使程宗利无法确切知晓查勘及定损结果，进而使程宗利丧失了第一时间寻求救济的权利，故人保公司应当对0°C以下低温未造成花器官受损的事实承担举证责任，举证不能的，应承担不利后果。

- 原文摘录：房还女与杨大勤之间的土地互换是双方的真实意思表示且各自在互换后的土地上经营管理多年，所以换地双方虽然未签署书面协议，其口头换地协议亦合法有效。……本案中的土地互换虽然没有经过村委会的备案和变更登记，但是不影响土地互换的效力。……双方未约定期限的，则视为期限至本轮土地承包期结束（即2028年9月30日）。

## 民勤县某蔬菜产销专业合作社诉某财产保险股份有限公司民勤支公司财产保险合同纠纷案（medium）

- 案号：（2022）甘0621民初873号｜法院：甘肃省民勤县人民法院｜类型：露地蔬菜综合收入保险合同（农业保险合同）

- **裁判要旨**：法院认定双方保险合同成立并生效，娃娃菜受灾符合保险条款第三十五条第（五）项约定的冻灾，属于保险事故；保险期间自2021年8月27日至12月26日的约定系双方真实意思表示，合法有效。保险公司接到报案查勘后未及时定损、未书面通知拒赔，确定损失程度的义务在保险人，由此产生的后果由保险公司承担，认定损失率已达30%以上；但被保险人未在娃娃菜成熟后及时采收，也未举证采取必要合理减损措施，酌定保险公司承担70%赔偿责任即402500元，合作社自担30%。因投保单、保险单未附保险条款全文且无证据证明保险人履行说明义务，涉案免责条款对保险公司无效。
- **风险规则**：

    - 启示：在农业保险及订单农业合同中应明确查勘、定损的时限和书面通知义务，并约定未及时定损的后果归属；投保人/农户出险后应及时报案、配合查勘并留存报案记录、查勘记录和损失证据，避免损失范围、受损面积表述前后不一。
  - [其他] 合作社于2021年11月3日向县政府指定接收单位捐送1.5亩娃娃菜，说明当时娃娃菜已经成熟可以采收，但未在成熟后及时采收；对于灾情发生后采取了哪些必要合理措施防止或减少损失，合作社并未举证。 → 法院依据保险条款第二十一条认为，知道保险事故发生后，被保险人应该尽力采取必要、合理的措施防止或减少损失，否则对因此扩大的损失，保险人不承担赔偿保险金的责任；合作社未在娃娃菜成熟后及时采收，也未举证采取必要合理措施，因此造成的损失应由其自行承担部分责任；综合本案实际情况，酌定保险公司承担70%赔偿责任，合作社自行承担30%责任。
    - 启示：农作物成熟后应及时采收，或在冻灾等灾害性天气来临前采取覆盖、保温等减损措施，并保留已采取减损措施的证据；否则可能被认定对扩大的损失存在过错，需自行承担部分损失。
  - [其他] 涉案保险合同订立时仅有投保单及保险单，投保单与保险单上均未附保险条款基本内容，保险公司亦未向合作社提供该条款全文，也无证据证实就该条款内容向合作社作出应有的解释与说明。 → 法院依据《中华人民共和国民法典》第四百九十六条第二款、《中华人民共和国保险法》第十七条、《最高人民法院关于适用〈中华人民共和国保险法〉若干问题的解释（二）》第十三条规定认为，保险公司未履行提示或者说明义务，应该认定在缔约阶段保险公司未履行说明义务，涉案保险条款免责事由对保险公司无效。
    - 启示：提供格式合同一方应就免除或减轻己方责任、与对方有重大利害关系的条款，以显著方式提示对方注意并作出明确说明，同时留存已提示、说明的证据；订单农业合同中的免责、限责条款若未尽提示说明义务，可能不产生效力。
- 原文摘录：双方在保险单中约定保险期间自2021年8月27日零时起，至2021年12月26日二十四时止，该约定系双方真实意思表示，符合上述保险条款约定，亦不违反法律规定，应当有效。在发生损失后难以立即确定损失率的情况下，确定损失程度的义务人为保险人，而非被保险人。保险公司在接到报案到现场查勘后未及时定损，使得定损条件丧失，且其未就拒绝理赔及原因进行书面通知，由此产生的后果应由保险公司承担。

    - 启示：合同应约定逾期付款的利息或违约金计算标准（计息基数、利率、起算日），并在履约中留存计息依据，否则逾期资金占用损失难以获赔。

    - 启示：合同宜约定送达地址确认条款和争议解决方式，一方违约后应及时以书面方式催告并保留送达凭证，避免对方消极不应诉导致回款周期拉长。
- 原文摘录：本院认为，本案系农机作业服务合同纠纷，原被告权利义务明确。根据《中华人民共和国民法典》第五百零九条规定：“当事人应当按照约定全面履行自己的义务”、第五百七十九条：“当事人一方未支付价款、报酬、租金、利息，或者不履行其他金钱债务的，对方可以请求其支付”。故本院对原告请求被告支付托管费用13300元的诉讼请求予以支持。利息原告未向本院提交证据加以证明，应当承担举证不能的后果。

## 吴某、梁某与张某、赵某农业承包合同纠纷二审民事判决书（medium）

- 分类：土地流转｜文书：判决书｜金额：土地转包费、押金共计1,620,000元（1,620,000元，一审表述为一千六百二十万元整，按上下文为1,620,000元）

  - [其他] 吴某、梁某在明知张某无涉案土地转包权的情况下仍转包涉案土地并付款，其后主张资金占用利息89,026元。 → 法院认为吴某、梁某对签订合同时即知晓案涉土地不得私自转包的事实予以认可，二人对合同的签订存在过错，且未提交能够证实其存在资金占用期间利息损失的证据，故对其资金占用利息请求不予支持。

## 民勤县育明蔬菜产销专业合作社与中国大地财产保险股份有限公司民勤支公司财产保险合同纠纷案（medium）

- 案号：（2023）甘06民终185号｜法院：甘肃省武威市中级人民法院｜类型：财产保险合同（露地蔬菜综合收入保险）
- 分类：农业保险｜文书：判决书｜金额：投保数量244.48亩，单位保险金额2500元，共计保险金额611200元，保险费24448元，农户自行负担4889.6元
- **核心争议**：合作社投保的娃娃菜在保险期间内因寒潮冻灾受损，是否属于保险事故及保险公司应否赔偿、赔偿数额如何确定。
- **裁判要旨**：二审认为保险合同及保险期间约定有效；寒潮导致投保娃娃菜冻灾属于保险事故。保险公司接到报案后未及时查勘定损并书面通知核赔结果，应承担赔偿责任；合作社未及时采收、未采取防冻措施亦有过错，一审酌定保险公司承担70%、合作社自担30%，赔偿402500元，二审驳回上诉、维持原判。
- **风险规则**：
  - [自然灾害] 保险期间内发生寒潮、降温、降雪，娃娃菜受冻；保险人以保险期间超出娃娃菜生长周期、不属于保险事故为由拒赔。 → 法院认定双方在保险单中约定的保险期间系双方真实意思表示，亦不违反法律规定，属于有效约定；根据气象证明、现场视频及专家意见，2021年11月5日至7日出现寒潮，发生投保娃娃菜遭受冻灾的事实，该事故属于保险合同约定的保险事故，大地财险民勤支公司应当予以赔付。
    - 启示：在农业保险或订单农业合同中明确自然灾害（冻灾、寒潮等）的定义、保险期间与农作物生长期的对应关系，并约定气象证明、现场影像等作为出险和定损依据。

  - [质量争议] 家庭农场主张的损失包括翻地费、种子、地膜、化肥、农药、滴灌带、主管带、副管带、开关、人工费、车工等，凭证多为白条或收据；作业方主张应通过专业鉴定确定损失项目及数额，并称管带可多年使用、地膜系政府免费提供、翻种不影响化肥肥力。 → 法院认为，翻地费用、种子、地膜、农药、滴灌带、主管带、副管带、开关、人工费、车工均为一次性费用且实际发生，予以支持；朱某丰称滴灌带能使用3—4年、地膜系政府免费提供，均未提供证据证明，且翻耕后地膜无法重复使用；化肥因复耕复种时种子位置与第一次不同、无法有效发挥肥力作用，基于化肥没有完全失效支持重新施肥费用的50%。
    - 启示：合同应预先约定作业不合格时的损失计算口径（投入品单价、亩数、人工单价、管带等材料是否一次性消耗），并明确损失以正规票据、转账记录等可核验凭证为准；主张材料可重复使用、投入品系无偿取得的一方负有举证责任，否则不获支持。
  - [拖欠款项] 农场未支付耕种费，朱某丰反诉主张共耕种250亩、要求支付耕地播种费20000元，但未能提供证据证明亩数。 → 法院认为，朱某丰主张耕种250亩未能提供证据证明，家庭农场认可耕种了86亩玉米和105亩刀豆，故综合认定耕种86亩玉米及105亩刀豆；农场认可未支付105亩刀豆耕种费用，应支付8400元；对于86亩玉米耕种费，因朱某丰的原因造成出苗欠佳、未能履行约定的义务，且造成农场对86亩玉米全部翻种，对其该部分耕种费主张不予支持。
    - 启示：合同应约定按地块、亩数、作物种类的作业确认单（双方签字或电子确认），并设置作业质量不合格时服务费的扣减、拒付或返工作业条款，避免事后亩数无从举证以及“部分作业合格、部分不合格”时费用如何结算产生争议。
  - [自然灾害] 朱某丰主张出苗率低的根本原因是土壤黏性大、雨后不适宜播种，且播种后遇大雨导致地面板结，天气原因是出苗率低的重要原因，并提交了他人证明及证人刘某珍证言。 → 法院未采纳天气原因免责的主张，认定朱某丰耕种的86亩玉米出苗欠佳是其自身原因所致；家庭农场提交了2023年3月29日至2023年4月2日没下雨的天气报告，朱某丰对该证据质证仅表示不认可、没有相关部门盖章。
    - 启示：合同应约定天气、墒情等自然因素导致作业效果不佳时的风险分担与通知、暂停作业机制；主张自然灾害免责的一方应及时取得气象部门等权威机构出具的证明，并保存作业时点的天气与土壤状况记录，证人证言、无盖章材料一般不足以推翻对方的气象证据。
- 原文摘录：被上诉人提交的经营者李某成与上诉人朱某丰的通话录音中，朱某丰认可了机器种植的玉米没能正常出苗是其自己的责任，结合土地现场视频、照片，证人证言等能够证明其耕种的86亩玉米出苗欠佳是朱某丰原因所致。因案涉土地在玉米没能出苗后已重新耕种，已不具备鉴定条件。

## 刘某某与邢某某农机作业服务合同纠纷二审民事判决书（medium）

- 案号：（2024）吉07民终1302号｜法院：吉林省松原市中级人民法院｜类型：农机作业服务合同
- 分类：农机作业｜文书：判决书｜金额：案涉《农机作业服务合同》合同总价款为94,800.00元（作业面积4000亩）；刘某某主张另存在标的额85,800.00元的口头合同，未被法院认可

- **裁判要旨**：二审认为刘某某虽持有85,800.00元发票，但该发票科目为穗禾公司与洮南市博敏信息咨询有限公司之间的运输费，且系刘某某本人开具，无法证明其与原穗禾公司另存在合同关系；刘某某自认85,800.00元系接受邢玲翠指示、为邢玲翠干活，与上诉主张的合同相对人相悖。邢某某持有支付79,900.00元的票据，证明该款系履行94,800.00元合同项下给付义务，故已付款应在案涉合同中冲减，欠款14,900.00元。一审判决认定事实清楚、适用法律正确，驳回上诉，维持原判。

- **风险规则**：

    - 启示：违约金标准不宜约定过高（如日1%），宜采用与资金占用损失可比的标准（如LPR的1.3—2倍）；同时应保留因迟延付款产生实际损失的凭证，否则法院将按资金占用利息酌减。
  - [其他] 同一作业方与同一付款人之间存在一笔书面合同（94,800.00元）和一笔口头作业（85,800.00元），付款方多笔转账未注明对应合同，双方对已付款冲抵对象发生争执 → 法院认为，刘某某主张存在85,800.00元的农机作业服务合同，邢某某不予认可，刘某某对该合同存在负有举证责任，但其提供的证据无法证明；刘某某已收到79,900.00元应冲抵案涉94,800.00元合同的价款，刘某某对于其他合同的主张应另案诉讼。
    - 启示：多批次作业应逐笔签订书面合同并载明作业地块、面积、单价与结算周期；每笔付款应在收据或对账单上注明所对应的合同编号与款项性质，避免已付款冲抵归属不明。
  - [其他] 刘某某开出一枚85,800.00元的增值税发票，票面购买方为穗禾公司，科目却为穗禾公司与洮南市博敏信息咨询有限公司之间的运输服务费，用以替代所谓的农机作业口头合同金额 → 法院认为，刘某某虽持有金额为85,800.00元的发票，但刘某某自认是本人去税务机关开具，科目信息却为穗禾公司与洮南市博敏信息咨询有限公司之间产生的运费，因此无法通过该税票证明刘某某与原穗禾公司存在另外的合同关系；该票面为85,800.00元的税务发票是否基于真实的合同关系开具、合同相对人如何确定等问题，均非本案审理范围，刘某某可依法另案主张权利。
    - 启示：发票科目、金额、购销双方必须与真实交易一致，不得以运费发票等替代服务款发票；以票代约无法替代书面合同，反而削弱主张方的证明力。
  - [主体不适格] 与刘某某签约的松原市穗禾农业开发有限公司于2023年11月23日未经依法清算即注销，注销前仅有股东邢某某一人，刘某某遂申请将被告变更为股东邢某某 → 一审法院认为，穗禾公司于2023年11月23日未经依法清算即注销，且注销前仅有邢某某一名股东，根据民事诉讼法解释第六十四条规定，未依法清算即被注销的，以该企业法人的股东、发起人或者出资人为当事人，邢某某为本案的适格被告。
    - 启示：与公司、合作社签订农机作业或订单农业合同时，应核查其存续状态、股东构成与清算情况；对方主体注销后，可依法向未依法清算的股东、发起人或出资人主张责任，但会显著增加诉讼成本与举证难度。
  - [质量争议] 邢某某主张刘某某施工不合格给其造成损失，刘某某不予认可 → 法院认定，邢某某主张刘某某施工不合格给其造成损失，刘某某不予认可，邢某某对此未提供证据；且邢某某已自认该合同于2022年8月之前履行完毕并于2022年11月就该合同支付相应款项，故应视为农机作业在履行完毕时已经验收合格。
    - 启示：合同应明确约定现场验收的方式、期限与验收单签署要求；发包方如主张作业质量不合格，须在验收环节及时书面提出并留存证据，否则视为验收合格，事后难以抗辩。
- 原文摘录：双方在合同中约定了违约金的计算方式，并主动降低违约金的计算方法，但违约金兼具惩罚性和补偿性功能，因此主张违约金应当以实际造成损失为基础。庭审中，刘某某未能就其实际损失进行举证，故对穗禾公司未及时给付劳务费，给刘某某造成的实际损失认定为资金占用期间的利息，酌定调整至一年期贷款市场报价利率的1.3倍。

## 吕某某与张某某、陈某某农机作业服务合同纠纷二审民事判决书（medium）

- **核心争议**：土地承包合同约定的承包期限届满后未续签，实际种植人是否仍应按原合同约定上交2019年-2021年承包费、水电费、滴灌使用费并承担逾期违约金。
- **裁判要旨**：二审法院认为，合同虽约定承包期限为2014年3月1日至2018年11月1日，但合同表中明确约定2018年-2023年每亩上交65公斤籽棉，上交年限已覆盖2019年至2021年，双方形成事实上的土地承包关系，施某某应按原合同履行上交义务。实际种植人施某某否认种植却无相反证据，一审法院调查周边农户证实其实际种植，其应承担举证不能后果；一审判决的承包费、水电费、滴灌使用费及按LPR分段计算的违约金予以维持，驳回上诉。
- 违约条款：合同约定：上交地租及各项费用必须在每年的10月31日前一次性交给甲方（甲公司），逾期不交者视为违约，甲公司有权解除合同，收回土地，并保留追诉所欠费用；签订合同时乙方（施某）每亩地预交合同保证金500元。甲公司一审主张违约金以未付款金额为基数，按一年期贷款市场报价利率并上浮50%计算至本息还清为止。
- **风险规则**：
  - [合同解除] 合同约定的承包期限为2014年3月1日至2018年11月1日，但合同第二条表1“承包期内每年上交籽棉数量”约定“2018年-2023年每亩上交数量为65公斤”，期限条款与上交数量条款的年限不一致，且期满后双方未续签合同而土地继续被种植。 → 法院认为，虽然施某某、施某在涉案合同期满后未与甲公司续签合同，但在原合同中约定的上交年限已覆盖了2019年至2021年，施某某应当按照合同约定每亩65公斤籽棉履行合同义务，双方已形成事实上的土地承包关系，故一审法院参照原合同确定由施某某支付2019-2021年承包费155480元及水电费、滴灌使用费43269.94元、违约金21145.21元具有事实及法律依据。
    - 启示：起草土地承包/订单农业合同时，承包期限条款与交售数量、费用标准的约定年限必须一致；期限届满前应书面续签或签订终止交接确认书，避免出现“期满未续签但仍继续种植”的事实承包状态，使费用标准失去明确依据。
  - [主体不适格] 《土地承包合同》由甲公司与施某签订（施某系施某某儿子），但合同履行期间案涉92亩土地由施某某实际经营种植，签约人与实际种植人不一致。 → 法院认为，涉案92亩土地虽然由甲公司与施某签订土地承包合同，但在合同履行期间由施某某实际种植了涉案92亩地；施某某否认其2019年至2021年在合同期满后继续种植，但没有相反证据证明涉案土地已交由他人种植，而甲公司通过一审法院调查涉案土地周围农户，均能证明施某某于2019年至2021年期间种植了涉案土地；施某某无法证明涉案92亩土地在其本人种植期满后已交还甲公司或者由其他人实际种植，应承担举证不能的法律后果，一审法院判决由其按照甲公司与施某签订的合同履行义务并无不当。甲公司主张施某承担上交责任，未出示证据予以证明，对该诉求不予支持。
    - 启示：合同应明确载明实际经营种植主体，要求签约人与实际种植人一致，或由实际种植人共同签署、出具授权/连带责任承诺；收取承包费、水电费等应针对实际用地方，并保留交地、退地、对账的书面凭证，避免仅凭证人证言认定种植主体。
  - [拖欠款项] 合同约定承包费及各项费用须于每年10月31日前一次性交清，逾期视为违约；施某某2019年至2021年实际种植后未按约定向甲公司交纳承包费、水电费、滴灌使用费。 → 法院认为，施某某于2019年至2021年实际种植案涉土地，应向甲公司交纳案涉土地相关费用，其未按约定交纳，故甲公司主张施某某赔偿违约金的诉求予以支持；但法院未按甲公司主张的以一年期贷款市场报价利率上浮50%全额计算，而是按各期LPR分段核定，2019年支持8,760.08元、2020年支持6,526.6元、2021年支持5,858.53元，违约金合计21,145.21元，对超出部分不予支持。
    - 启示：逾期付款违约金应约定可分段计算、随LPR浮动并可溯及具体欠款期间的算法，同时保留完整的费用计算依据（面积、单价、文件依据）；主张过高违约金可能不被全额支持，宜在合同中设定与损失相称的违约金标准并配套对账与催收机制。
  - [价格波动] 合同约定按照合同面积每年每亩交地租为一级籽棉，如种植其它作物以当年籽棉价（以当年乙公司与甲方的籽棉结算价为准）折成现金上交；承包费单价取决于乙公司依据当年棉花市场价格下发的目标价文件。 → 法院依据乙公司温永发【2020】5号、温永发【2020】13号、温永发【2021】21号等文件认定2019年-2021年棉花单价分别为7.5元/公斤、7.5元/公斤、11元/公斤，依据温永发【2019】22号、温永发【2020】21号、温永发【2021】22号文件认定2019年-2021年水电费每亩分别为100.5569元、103.1625元、116.6061元，并据此计算承包费、水电费及滴灌使用费。
    - 启示：以实物折价或挂钩第三方价格文件的定价条款，应写明价格文件的发布主体、文件名称、适用年度以及文件未发布或无法送达时的替代定价与争议解决方式，并约定每年度的价格确认与书面通知程序，避免因价格来源不确定产生折算争议。
  - [其他] 上诉人主张甲公司申请出庭的证人马某某与其有利害关系、一审质证程序有瑕疵，并提交另案民事判决书用以否定证人证言的证明力。 → 法院认为，该另案判决书与本案争议焦点问题无关联性，故对该证据的证明力不予确认；施某某主张证人与其有利害关系及一审法院对证人证言质证程序有瑕疵，没有事实及法律依据；一审法院认定事实清楚、适用法律正确，予以维持。
    - 启示：合同履行中应主动固定客观证据（土地交接单、种植与采收记录、费用对账单、付款凭证、书面催告），不要使关键事实只能依赖证人证言；对相对方提交的“利害关系”抗辩，应准备独立于证人的书证、物证形成证据链。
- 原文摘录：甲公司与施某签订的土地承包合同第二条乙方的权利与义务项下表1：承包期内每年上交籽棉数量部分明确约定：“2018年-2023年每亩上交数量为65公斤。”故施某某、施某虽然在涉案合同期满后未与甲公司续签合同，但在原合同中约定的上交年限已覆盖了2019年至2021年，故施某某应当按照合同约定上交数量每亩65公斤籽棉向甲公司履行合同义务，双方已形成事实上的土地承包关系。

## 灌南县张店镇***村民委员会与施**土地承包合同纠纷一审民事判决书（medium）

- 案号：（2024）苏0724民初584号｜法院：江苏省灌南县人民法院｜类型：农村土地流转（土地承包）合同
- 分类：土地流转｜文书：判决书｜金额：约定流转200.78亩（以实测为准），每亩每年租金1000元（其中土地租金900元/亩，余100元/亩为甲方管理费）；实际交付135亩；判决支付土地承包费67500元

- 违约条款：乙方如果在未经甲方同意前提下擅自不再租赁经营，需要提前9个月向甲方说明并征得甲方同意，否则需要赔偿5万元违约金给甲方，丙方对此承担连带保证责任；如果乙方有不及时支付租金等违约现象，甲方有权立即终止合同并按日支付甲方违约金1000元/天。甲方如果不再租地给乙方需要在水稻收割前45天向乙方告知。
- **风险规则**：
  - [拖欠款项] 合同约定乙方需在每年9月30日前支付租金，被告仅支付了2021年11月至2022年9月的租金，此后年度租金未付，原告多次催要未果。 → 本院认为，原被告签订土地流转合同书，双方形成土地承包合同关系，被告应按照合同约定支付2022年10月至2023年6月的土地承包费，但被告未予支付，故对原告主张上述期间半年的承包费67500元（1000元/年/亩×0.5年×135亩）符合合同约定以及法律规定，本院予以支持。
    - 启示：土地流转/订单农业合同中应明确租金（或收购款）的支付时间节点、实际交付亩数以实测为准的结算口径，并约定欠付时的催告与终止程序，便于按实际交付面积和实际占用期间主张价款。
  - [合同解除] 被告于2023年5月提出解除合同、不再承包案涉土地，原告于2023年6月将案涉土地另行向案外人发包。 → 被告于2023年5月提出解除合同后，原告已于2023年6月将案涉土地向案外人发包，应视同原告同意被告解除合同，案涉合同已经实际解除，故原告解除案涉合同以及承担违约金5万元的诉请，本院不予支持。
    - 启示：守约方在对方提出解约后若另行将土地发包或另行处置标的物，可能被认定为以行为同意解除，从而丧失主张约定违约金的基础；如不同意解除，应及时书面明确拒绝并保留证据，避免同时接受对方履行或另行处分标的物。
  - [擅自处分] 原告主张被告未经其同意擅自将承包土地转包给他人种植；被告辩称转包已告知原告且原告认可，原告还直接要求第三人缴纳土地承包费用。 → 法院查明被告将所承包土地转包案外人，原告亦向案外人发包并于2023年6月将案涉土地向案外人承包；判决仅就欠付承包费作出处理，未就擅自转包单独认定违约责任。
    - 启示：合同应明确约定是否允许转包/分包、转包的书面同意程序及违反的后果，并约定出租方直接向次承租人收取费用是否构成对转包的追认，以免争议时无法追究擅自处分的责任。
- 原文摘录：被告于2023年5月提出解除合同后，原告已于2023年6月将案涉土地向案外人发包，应视同原告同意被告解除合同，案涉合同已经实际解除，故，原告解除案涉合同以及承担违约金5万元的诉请，本院不予支持。

## 华某与顾某某土地承包经营权纠纷民事二审判决书（medium）

- 案号：（2024）苏08民终714号｜法院：江苏省淮安市中级人民法院｜类型：土地承包经营权流转协议转包合同（土地转包用于种植经营）
- 分类：土地流转｜文书：判决书｜金额：承包土地面积420亩，土地年租金总额260400元（每亩620元每年）；承包期限共二年半，自2022年1月20日起至2024年6月10日止；顾某某已支付华某280000元，其中260400元为一年期土地租金，19600元为机耕作业费用及几十亩青苗费用补偿
- **核心争议**：土地转包合同提前解除后，出租人华某是否应返还其已收取的一年期租金中超出实际租期部分的58500元。

    - 启示：约定长期承包/收购期限并按年（季）预付价款的合同，应明确约定合同解除的条件、解除生效日，以及解除后已付价款按实际使用/交付期间结算并退还余额的计算方式，避免预付整年款项与实际履行期不匹配产生返还争议
  - [其他] 出租人主张租金应自2021年11月1日（油菜季）起算，理由是其在签约前已将土地交付并耕种油菜、自他人处承租期间亦发生租金；但交付时间与起租时间在合同中未明确固定 → 华某主张实际履行期限自2021年11月1日开始，未提供证据证明，应承担举证不能的法律后果，故华某要求顾某某承担2021年10月30日至2022年1月20日期间租金无事实及法律依据，本院不予采纳

    - 启示：合同中应将租金与前期投入（机耕、青苗、水电设施等）补偿款分项列明，写明款项性质、对应期间及合同解除时是否退还，防止款项性质混淆导致结算与返还争议

## 莱西市某甲村民委员会与隋某冬土地承包经营权纠纷一审民事判决书（medium）

- 案号：（2024）鲁0285民初486号｜法院：山东省莱西市人民法院｜类型：土地承包合同（口头叫行承包，涉庙儿壃、桃树地、干渠西三宗土地）

    - 启示：订单农业合同应书面约定标的、数量、价格标准、结算周期与逾期付款利息，并留存每期交款凭证与对账记录；口头约定一旦发生争议，主张方对约定内容及调价合意承担举证责任。
  - [主体不适格] 原发包方“莱西市某乙村民委员会”已撤销，与莱西市日庄镇白石山村等村合并设立“莱西市某甲村民委员会”，由新村委会主张承包费。 → 法院认定，隋某冬与原村委会之间土地承包合同成立且合法有效，现该村委会已撤销，相关权利义务由莱西市某甲村民委员会承继，莱西市某甲村民委员会当然成为案涉土地承包合同相对方，承担合同义务，享有合同权利。

- 原文摘录：案涉土地承包合同对合同相对方具有约束力，双方均应按合同约定履行义务，未经对方同意，单方变更合同内容的行为无效；双方可在协商一致的前提下，协议变更合同内容。……关于“干渠西”，在隋某冬未予认可的情况下，原莱西市某乙村民委员会单方增加土地承包费的行为无效，双方应按照原合同约定的承包费数额执行。

## 黄岛区某某镇吕某村股份经济合作社与青岛某某园果蔬专业合作社土地经营权出租合同纠纷（medium）

- 案号：（2024）鲁02民终10413号｜法院：山东省青岛市中级人民法院｜类型：农村土地经营权出租合同（原名为《农村土地承包经营权流转合同》）

  - [其他] 合同第七部分第1条约定“如遇国家或地方政府征用该宗土地……本合同自行终止，双方互不追究违约责任”，但实际仅部分土地被征收，双方未就剩余土地的履行或终止进行约定和协商。 → 一审法院认为，该条款主要系对征收时补偿费用分配、已付租赁费处理及合同责任的约定，是否适用部分土地被征收的情形双方并未作明确约定，某某路西延项目仅占用被告所承租的部分土地并非全部，被告仅据此认定合同已自动解除过于绝对；即使涉及被征收部分的合同权利义务自动终止成立，就剩余部分土地，被告自始至终未向原告作出合同终止或解除的意思表示，且于2020年5月又支付全年租金，以其事实行为表明继续履行合同的意愿，故合同已于2019年8月自动解除的抗辩不能成立。二审维持该认定。

  - [其他] 修路工程东西横穿整个园区，征收范围覆盖并破坏了园区水肥一体化灌溉系统与供电系统的核心区域，园区唯一水源也遭到破坏，征收范围之外的园区无法按原规划正常使用。 → 一审法院依《民法典》第七百二十九条认为，部分承租地被依法征收致该部分土地不能继续使用，该部分租赁费原告不能再主张；经现场勘验，因征收破坏核心设施与唯一水源，园区其他部分已无法按原规划正常使用，且原告未采取积极措施提供适租条件、未防止损失扩大，对土地荒置亦负有责任，故被告有权要求减少租金，酌定剩余面积土地租赁费按合同约定标准的80%计算。二审认为该酌定并无不当。

  - [合同解除] 园区经整体建设形成不可分割的有机整体，征收对其造成根本性破坏，征收范围之外的园区不存在单独运行的现实可操作性，承租人难以按原规划继续种植经营，且在答辩中明确提出解除合同的请求。 → 一审法院认为案涉园区原本已进行道路建设、水源地开发、电力系统、现代化水肥一体化设施建设，形成不可分割有机整体，征收已对园区整体造成根本性破坏，被告已无法实现合同目的，为打破僵局、减少诉累，合同应依法予以解除；二审进一步明确，一审法院根据沃某某园某某社答辩时提出的解除请求，判决合同自一审判决作出之日起解除，并无不当。
    - 启示：长期农业经营类合同应明确约定解除权的行使条件、行使方式以及解除时间的确定规则（通知到达日或裁判生效日），并同步约定解除后地上附着物清理、设施处置与土地返还的期限和责任，防止出现“判而不清、地不能耕”的僵局。
  - [拖欠款项] 承租人支付了2019、2020年度全部租金后未再支付2021—2023年度租金，但现场仍有其工作人员看管、部分护栏围挡，且从未将剩余部分土地实际返还出租方。 → 一审法院经2023年12月8日现场勘验认为，除被征收范围外，被告承租园区其他部分仍有部分护栏围挡并有相关人员看管，虽被告未继续经营，但未将剩余部分土地实际返还原告，因合同未自动解除，被告应向原告支付尚未征收部分土地的租赁费；二审维持，认为承租人应向出租方支付剩余部分土地的租赁费。
    - 启示：合同应约定承租人停止经营时的土地交还程序与确认方式（交还时间、验收标准、书面交接单），并明确未办理交还前占用期间的费用承担规则，避免出现既不支付租金又不返还土地的双重僵局。
  - [合同解除] 出租方主张按合同约定支付违约金241346.16元；合同同时约定征收情形下“本合同自行终止，双方互不追究违约责任”，且双方在征收后均未积极协商解决剩余土地问题。 → 一审法院认为违约金应以损失为基础，兼顾合同履行情况、当事人过错程度，根据公平原则和诚信原则衡量；本案系因政府征收土地导致合同无法正常履行，双方均未积极协商解决剩余部分土地的租赁问题，致使合同履行陷入僵局，双方均有过错，且征收补偿数额政府亦未与被告达成一致、被告尚未获得补偿并多次信访，故对违约金不予支持。二审认为一审不予支持并无不当。
    - 启示：违约金条款应与不可归责于双方的事由相衔接，明确政府征收、政策调整等情形下违约金是否适用及适用条件，并约定僵局出现后双方的协商义务与期限，避免因双方均有过错而导致违约金主张落空或责任无法划分。
- 原文摘录：案涉土地仅有部分被征收，关于剩余部分土地，双方从未就合同终止和解除达成合意，沃某某园某某社主张案涉合同自动终止，依据不足。因某某路西延项目土地征收，对案涉园区整体造成了根本性破坏，征收范围之外的园区不存在单独运行的现实可操作性，合同目的已无法实现……吕某村合作社未采取积极措施提供适租条件，未采取措施防止继续损失扩大，亦应承担一定责任。

## 丁某高与黄岛区某某经济合作社土地承包经营权合同纠纷（medium）

- 案号：（2024）鲁02民终3448号｜法院：山东省青岛市中级人民法院｜类型：土地承包经营权合同（以其他方式承包农村机动地的口头承包合同）
- 分类：土地流转｜文书：判决书｜金额：请求向原告横山某某合作社交纳3.18亩机动地2017年至2023年共七年的土地承包费11130元（2017年起按每年每亩500元计算）

- **裁判要旨**：二审认为，本案系以其他方式承包农村土地，双方未约定承包期限，承包费可由双方协商解决，协商不成的可解除合同、返还土地；上诉人认为每年每亩500元过高，但未与被上诉人协商解决，亦未解除合同返还土地，而是继续占用涉案土地且不再支付承包费，属不履行合同义务，应承担违约责任。一审判决上诉人交纳2017年至2023年土地承包费11130元并无不当，二审驳回上诉、维持原判。

- **风险规则**：
  - [价格波动] 双方仅口头约定承包费按每年每亩200元交纳，未签订书面合同约定费用调整机制；村集体经党员与村民代表表决自2017年起将承包费降至每年每亩500元并通知承包方，承包方主张仍应执行200元标准。 → 法院认为，本案系以其他方式承包农村土地，双方未约定承包期限，对承包地的费用确定可由双方协商解决，协商不成的可解除合同、返还土地；上诉人认为每年每亩500元承包费过高，但未与被上诉人协商解决，亦未解除合同返还土地，而是继续占用涉案土地、不再支付承包费，其不履行合同义务，应当承担违约责任。
    - 启示：土地流转及订单农业合同应以书面形式明确单价（承包费/收购价）及其调整机制、协商程序与异议救济方式，避免价格单方变更或长期沿用口头标准而引发费用争议。
  - [拖欠款项] 承包方自2017年起未交纳承包费，经催要仍欠付2017年至2023年共七年费用。 → 法院认定承包方不履行交纳承包费义务构成违约，应当承担违约责任，据此判令其支付2017年至2023年土地承包费11130元。
    - 启示：合同应明确约定付款时间、金额计算方式、书面催告程序及逾期付款违约责任（违约金或利息），以便在对方逾期时及时固定违约事实并主张损失。
  - [合同解除] 双方承包关系自1992年起延续，未签订书面承包合同，亦未约定承包期限，承包面积后经重新丈量确认为3.18亩。 → 法院指出，在双方未约定固定承包期限的情形下，若承包方不认可该承包费标准，其可以解除双方口头形成的土地承包合同并将涉案土地返还村集体；但其继续承包并占用涉案土地至今，应当自2017年起按每年每亩500元标准交纳承包费。
    - 启示：建议在土地流转合同中书面约定承包期限、面积（含测绘确认方式）、费用标准及解除条件与返还土地的程序，避免因无书面约定、无固定期限而在调价时只能通过诉讼解决。
- 原文摘录：根据《中华人民共和国农村土地承包法》第四十九条规定：“以其他方式承包农村土地的，应当签订承包合同，承包方取得土地经营权。当事人的权利和义务、承包期限等，由双方协商确定。”本案系以其他方式承包农村土地，且双方未约定承包期限，对承包地的费用确定可由双方协商解决，协商不成的可解除合同，返还土地。上诉人认为每年每亩500元承包费过高，但未与被上诉人协商解决，亦未解除合同返还土地，而是继续占用涉案土地，不再支付承包费，其不履行合同义务，应当承担违约责任。

## 薛某选与薛某亮、黄岛区某某经济合作社土地承包经营权纠纷二审民事判决书（medium）

- 案号：（2024）鲁02民终5514号｜法院：山东省青岛市中级人民法院｜类型：土地承包经营权转让合同
- 分类：土地流转｜文书：判决书｜金额：涉案2.22亩；按12400元／亩有价补偿给乙方，补偿款计27528元。另有2022年《土地承包经营权自愿退还协议》约定征地补偿安置费7.68万元／亩、清场奖励费3000元／亩等，但法院认定该协议未生效和实际履行。

    - 启示：起草土地流转或农业用地合作合同时，应明确写明流转方式（转让、转包、出租等），并明确原承包合同关系是否终止、承包面积是否核减、发包方是否同意或备案、补偿款性质及支付方式，避免因约定不明引发合同性质争议。
  - [主体不适格] 土地承包经营权转让需经发包方同意并由发包方在转让合同上签署意见并加盖公章；上诉人主张村委会不知情、公章系私盖，并申请鉴定。 → 法院认为协议加盖了河南某某村委会单位公章，河南某甲合作社曾撤回鉴定申请并承认公章真实性；退一步讲，即使没有加盖公章或公章是后加盖的，根据司法解释但书，发包方无法定理由不同意或者拖延表态，不影响土地承包经营权转让合同的效力。
    - 启示：涉及土地承包经营权转让的，应取得发包方书面同意并加盖公章，最好同步取得发包方同意文件、会议记录或备案回执；避免仅依赖事后盖章或口头同意，减少公章真实性、形成时间及是否同意等争议。
  - [擅自处分] 受让方取得土地后改变农用地用途，将基本农田硬化、建设房屋、开设驾校、用于煤炭经营等；上诉人以此主张协议违反法律强制性规定而无效。 → 法院认为，受让方在使用过程中改变了原有用途，但其已受到行政处罚并予以纠正，且与本案并非同一法律关系，故不影响《土地补偿协议》的效力。
    - 启示：合同中应明确约定土地用途仅限于农业生产经营，并约定擅自改变用途的违约责任、恢复原状义务和解除条件；同时应关注农用地用途管制与行政合规风险，避免因用途违法引发履行障碍。
  - [拖欠款项] 受让方诉请返还土地补偿款177156元及利息，但涉案土地未被政府征收，发包方与承包方签订的《土地承包经营权自愿退还协议》未生效、未履行，补偿款未实际发放。 → 法院认为涉案土地并未作为人民政府征收决定的对象，而是拟由集体经济组织收回；《土地承包经营权自愿退还协议》未生效和实际履行，补偿款未发放，涉案土地仍由原告实际管理使用，故主张各项补偿款及利息证据不足，不予支持。
    - 启示：在土地流转或订单农业合同中，应明确征收、收回、补偿款归属及支付条件、支付主体和触发节点，并确保相关前置协议依法生效、盖章履行；避免在补偿条件未成就时主张款项。
- 原文摘录：本院认为，根据双方签订的《土地补偿款协议》中约定的“按12400元/亩有价补偿给乙方”“该补偿地2.22亩，从乙方30年土地承包合同确定的面积核减下来”“本协议一式三份，甲乙双方及村委会在原土地合同中各附一份”及收条、原审被告在协议上加盖公章等，综合分析，本院认为《土地补偿款协议》符合土地承包经营权转让合同特征。……《土地补偿协议》系双方真实意思表述，未违反法律、行政法规的强制性规定，故合法有效。

## 李某兰与中国某某财产保险股份有限公司聊城市中心支公司财产保险合同纠纷一审民事判决书（medium）

- 案号：（2024）鲁1521民初983号｜法院：山东省阳谷县人民法院｜类型：财产保险合同（玉米完全成本种植保险）
- 分类：农业保险｜文书：判决书｜金额：保险单载明：单位保险金额950元／亩，保险费194104.68元；李某兰保险数量3.94亩，总保险费165.48元，农户自交保险费33.10元；判决赔偿3743元（3.94亩＊950元／亩）
- **核心争议**：村委会以集体投保方式为村民投保玉米完全成本保险，被保险人李某兰实际在被保险地块种植地瓜并因虫害减产，其要求保险公司按地瓜损失赔偿，保险公司以保险标的为玉米、不含地瓜为由拒赔。
- **裁判要旨**：法院认定村委会投保、保险公司出具保险单，双方保险合同关系成立且合法有效。依《农业保险承保理赔管理办法》第十一条，保险机构承保种植业保险时应查验保险标的真实性、准确性，被告承保前原告已在被保险地块种植地瓜，被告未查验核实即收取保费致合同成立，应对原告损失承担赔偿责任；赔偿数额以《种植业保险分户标的投保清单》载明的3.94亩为准，按每亩保险金额950元计算，判赔3743元。
- **风险规则**：
  - [其他] 村委会以集体投保方式投保的是玉米完全成本保险，而被保险地块上实际种植的是地瓜，投保时投保人已将李某兰列入投保清单且其本人在农户签字栏签名 → 法院认为，根据《农业保险承保理赔管理办法》第十一条“保险机构应当对保险标的的真实性、准确性、权属和风险等情况进行查验，并妥善保存相关证明资料”，被告承保种植业保险时应当对保险标的真实性、准确性等进行查验核实；案涉保险虽为玉米种植保险，但原告在被告承保前已在被保险地块上种植了地瓜，被告承保时未按规定查验核实即收取原告保险费，致案涉保险合同成立，应当对原告的损失承担赔偿责任
    - 启示：承保或签订收购订单前，必须实地核验标的作物的实际种类、权属与面积，并在合同中明确记载标的作物品种，避免出现“保非所种”“收非所种”的标的错位；农户签字确认投保清单会强化合同的约束力。
  - [其他] 投保清单载明李某兰保险数量为3.94亩，而原告主张其实际种植地瓜6.5亩，双方对面积存在争议 → 法院认定，因原告提交的《种植业保险分户标的投保清单》中载明其保险数量为3.94亩，故认定原告李某兰的种植面积为3.94亩；原告虽称其种植了6.5亩地瓜，但并未提供被告承保数量为6.5亩的证据，依法不予认定
    - 启示：合同或投保清单中应精确载明标的面积/数量并由农户逐项签字确认，保管好面积测量、地块图等原始凭证，避免日后就面积数量发生举证不能的风险。
  - [其他] 原告提交村委会出具的证明用以证明地瓜减产70%左右，被告以该证明无法确定书写人、属证人证言应到庭接受询问、无其他证据印证为由提出异议 → 法院在认定事实时采信了高庙王镇某某村民委员会为李某兰出具的证明，即其种植的地瓜因受严重虫害造成减产70%左右，并结合“一般情况下地瓜亩产在4000斤-6000斤，按市场价格计算，原告的损失显然已超出保险合同约定的每亩保险金额”，按每亩保险金额950元确定赔偿
    - 启示：减产、质量等损失事实应尽量取得农业主管部门、专业鉴定机构出具的证据而非仅凭村委会单方证明；同时在合同中事先约定损失认定方式与赔偿上限（如每亩固定金额），以降低定损争议。
  - [其他] 保险单特别约定载明“保险玉米每亩保险金额确定为950元”，并约定保险期间、保险标的项目为玉米 → 法院认为原告损失已超出保险合同约定的每亩保险金额，故被告应当按照合同约定的每亩保险金额950元赔偿原告的损失
    - 启示：合同中应明确约定单位面积的赔偿限额与计算方式，一旦发生灾害或违约，可依约定金额直接结算，避免因实际损失难以举证而陷入僵局。
- 原文摘录：根据《农业保险承保理赔管理办法》第十一条“保险机构应当对保险标的的真实性、准确性、权属和风险等情况进行查验，并妥善保存相关证明资料。”的规定，被告承保种植业保险时应当对保险标的的真实性、准确性等进行查验核实。案涉保险虽为玉米种植保险，但原告在被告承保前已在被保险地块上种植了地瓜，被告承保时未按照上述规定进行查验核实即收取原告保险费，致案涉保险合同成立，应当对原告的损失承担赔偿责任。

## 林某源与王某贤土地承包经营权转让合同纠纷二审民事判决书（medium）

- 案号：（2024）黑10民终524号｜法院：黑龙江省牡丹江市中级人民法院｜类型：土地流转合同（土地承包经营权流转）

    - 启示：长期土地流转/订单农业合同应在签约时约定价格形成与调整机制（固定价、阶梯价或触发调价的客观标准），避免一方仅以市场价格涨跌为由拒收款项或主张解除、撤销。
  - [合同解除] 承包方以受让方未充分告知权利义务、利用其文化低不识字、土地为水改旱后拒绝调价等为由，主张合同可撤销并要求解除合同。 → 一审法院依《农村土地经营权流转管理办法》第二十条认定，受让方无擅自改变土地的农业用途、弃耕抛荒连续两年以上、给土地造成严重损害或严重破坏土地生态环境等情形，故承包方无合同解除权，双方应当继续履行合同；二审认为林某源主张欺诈、重大误解、显失公平未举示充分证据，应承担举证不能的法律后果。
    - 启示：合同中应明确约定解除权的行使条件与程序，并固定签约主体的行为能力与知情确认证据（如书面告知、签字确认、见证或录音录像），防止事后以重大误解、显失公平为由推翻合同。
  - [其他] 合同乙方原为王某贤与王某君两人，后王某君与王某贤签订《土地流转合同退出协议》，约定王某君退出、由王某贤一人继续履行合同。 → 一审法院认为，因王某君与王某贤签订《土地流转合同退出协议》，王某君退出土地流转合同，权利义务由王某贤一人承担，故王某贤作为原告主体适格，可以作为权利主体要求林某源继续履行合同。
    - 启示：多方共同受让土地或共同签约的订单农业合同，应预先约定各方份额、一方退出的内部处理方式及对外通知程序，避免履约主体与诉讼主体不明引发争议。
  - [其他] 合同约定的土地流转期限自2020年4月13日起至2030年12月30日止，而承包方承包土地期限至黑山村第二轮土地承包最后一年即2028年年末。 → 法院依《中华人民共和国农村土地承包法》第三十八条认定，流转期限不得超过承包期的剩余期限；经调查林某源承包期限至2028年年末，故双方约定的流转期限超过承包期剩余期限部分无效，对王某贤要求继续履行至承包期限届满的诉讼请求予以支持，超过部分不予保护。
    - 启示：签订土地流转或订单农业合同前，应核查承包方土地承包经营权证的剩余期限与地块性质（如水改旱），合同期限不得超过承包期剩余期限，并明确超期部分的处理方式。
  - [其他] 承包方在二审中提交同村2023年土地流转合同，用以证明案涉流转费用过低、土地价格上涨。 → 二审法院认为，该证据意在证明的土地价格上涨问题已经一审法院调查并作为本案事实予以认定，且双方当事人对一审判决认定的事实均无异议，不能以林某源与案外人签订合同时的意思表示来当然推定林某源与王某贤所签合同的效力，故对该组证据意在证明的问题不予确认。
    - 启示：合同效力争议应以签约时的约定和证据为准，签约时应留存价格协商依据与证据，履约中也应及时以书面方式固定变更合意的证据，单方参照案外同期合同主张调价通常不被支持。
- 原文摘录：本院认为，林某源作为完全民事行为能力人，签订合同时应尽到审慎审查义务，且土地承包费用的浮动系土地在承包、流转过程中的正常规律，为维护社会经济秩序稳定，本案案涉土地流转合同应当继续履行。

## 闫某某与苏某、某某公司农机作业服务合同纠纷一审民事判决书（medium）

- 案号：（2024）黑1283民初313号｜法院：黑龙江省海伦市人民法院｜类型：农机作业服务合同（有机肥抛撒协议）
- 分类：农机作业｜文书：判决书｜金额：约定抛撒面积预计为2万亩，实际作业面积为20055.6亩，每亩作业费18元，总计作业费为36.1万元；某某公司出具欠条载明欠抛撒款26.1万元，其后实际控制人张广富转账5万元，二被告尚欠作业费21.1万元未偿还。
- **核心争议**：农户（作业方）完成有机肥抛撒作业后，作业费经结算尚欠21.1万元，发包方及出具欠条的第三方公司是否应共同给付作业费及逾期付款利息。

- **风险规则**：
  - [拖欠款项] 协议仅约定“待乙方抛撒作业面积全部完成、审计合格拨款后，一次性支付乙方所有作业费”，付款时点与第三方审计、拨款进程挂钩，未约定明确付款期限和逾期违约责任。 → 法院认定“苏某未支付作业费的行为系违约”，并判令某某公司、苏某于判决生效后立即给付闫某某作业费211000元。
    - 启示：订单农业/农机作业合同应避免把付款条件完全挂靠“审计合格拨款后”等第三方流程，须约定确定的付款期限、结算确认方式和逾期付款违约金计算标准，以免回款长期悬空。
  - [其他] 第三方公司（某某公司）在结算现场为作业方出具26.1万元欠条、加盖公司公章并由其副总经理签字、实际控制人转账付款。 → 法院认为“某某公司为闫某某出具26.1万元的欠条并同意给付闫某某作业费，某某公司应与苏某共同履行给付闫某某作业费的义务”。
    - 启示：当发包主体资信不足时，应争取由有实力的关联公司或实际控制人以书面欠条、加盖公章方式确认并承担共同付款义务，同时保留转账凭证，便于主张共同给付责任。
  - [拖欠款项] 合同没有约定逾期付款违约金或该违约金的计算方法，作业方只得另行主张逾期付款利息损失。 → 法院依据最高人民法院《关于审理买卖合同纠纷案件适用法律问题的解释》第十八条，支持闫某某要求苏某与某某公司自2022年8月20日起至作业费实际给付之日止按照一年期贷款市场报价利率标准支付利息的诉讼请求。
    - 启示：合同应写明逾期付款的资金占用损失计算方式（如按LPR或LPR加计一定比例），并明确起算日，避免违约后只能依司法解释主张、举证与计算成本增加。
  - [其他] 作业方持有双方签订的抛撒协议、第三方出具的欠条等书面凭证；被告经传票传唤无正当理由拒不到庭，未作答辩、放弃质证。 → 法院认证认为“以上证据形式具有合法性，内容具有真实性，与本案具有关联性，本院予以采信”，并对原告的诉讼请求予以支持。
    - 启示：履约过程中应固定书面协议、作业面积结算依据、欠条/对账单等原始凭证并确保签章完备，对方缺席时法院可据以认定事实，降低回款诉讼的举证风险。
- 原文摘录：闫某某与苏某之间形成的有机肥抛撒协议意思表示真实，且不违反法律、行政法规的强制性规定，不违背公序良俗，原、被告之间设立的农机作业服务合同法律关系依法发生法律效力。苏某未支付作业费的行为系违约。某某公司为闫某某出具26.1万元的欠条并同意给付闫某某作业费，某某公司应与苏某共同履行给付闫某某作业费的义务。

## 张某卫与山东省青岛市莱西市某埠镇张某某村民委员会土地承包经营权纠纷二审民事判决书（low）

- 分类：土地流转｜文书：判决书｜金额：案涉土地年承包费2295元（675元＋1620元）；村委会起诉请求承包费20230元及利息；一审判决给付承包费15560元及利息。

  - [其他] 承包人在承包地上改造荒地、修建养殖场、种植冬枣树约60亩、杨树约40亩、白蜡树约4万颗、银杏树约300颗及四个虾池、房屋90多间等地上附属物，主张解除合同砍伐树木会造成大量经济损失。 → 法院认为，李某森以其地上附着物损失较大为由主张涉案合同不应解除，于法无据，其可另案主张相关权益；因双方对地上附属物价值及归属无法达成一致，经法院多次释明并告知风险，李某森坚持不申请评估鉴定，其主张补偿或赔偿因数额不明确，一审法院不予处理，涉案土地上的地上附属物应由李某森自行腾退。
    - 启示：承包/流转合同应事先约定合同终止时地上附属物、种植物、养殖设施的处理与补偿方式及评估鉴定程序，明确补偿范围与计算依据，避免解除或到期腾退时就地上物价值与归属产生争议且因举证不能而失权。
- 原文摘录：根据本案查明事实，上述合同到期后，双方虽未续签合同，但均认可由李某森继续占有使用涉案土地至今，故涉案合同已经转为不定期合同。一审法院由此认定双方均享有随时要求解除合同的权利，认定涉案合同已于李某森收到律师函之日即2023年11月20日解除，于法有据。

## 于某密与黄岛区珠海街道某家庄股份经济合作社土地承包经营权纠纷二审民事判决书（low）

- 案号：（2024）鲁02民终791号｜法院：山东省青岛市中级人民法院｜类型：土地承包经营权纠纷（承包地征收补偿费用分配）
- 分类：土地流转｜文书：判决书｜金额：土地补偿款数额为4760元，青苗补偿费2240元；原告诉请0.07亩计7000.00元
- **核心争议**：被征收的0.07亩菜园地土地补偿款，是按家庭承包方式发放给上诉人（于某密），还是应认定为登记人徐某某的个人财产（遗产）由全体继承人共同共有。
- **裁判要旨**：二审法院认为，案涉土地未办理登记且未签订农村土地承包合同，《珠海办某家庄关于查证登记当年村集体分配给村民菜园、打谷场的实施方案》亦载明“当时无任何资料显示：村两委会或上级曾承诺分给农户的打谷场和菜园三十年不变”，故一审认定该地块系分配给徐某某个人而非家庭承包方式承包、土地补偿款系徐某某遗产，并无不当；依《最高人民法院关于审理涉及农村土地承包纠纷案件适用法律问题的解释》第二十四条，集体经济组织可依民主议定程序决定内部分配已收到的土地补偿费，在合法继承人未对遗产作出分割前属共同共有，上诉人主张全额发放于法无据。遂驳回上诉，维持原判。
- **风险规则**：
  - [其他] 案涉0.07亩菜园地系1994年村委按人口统一分配、登记在徐某某个人名下，此前仅在村里有土地登记簿记载，未办理土地使用权证，双方亦未签订农村土地承包合同。 → 法院认定：案涉菜园地0.07亩系分配给徐某某个人的，并不是以家庭承包方式承包，并非系三十年不变的承包地；双方亦未签订农村土地承包合同，原告主张该地块为家庭户承包地证据不足。因案涉土地未办理登记且未签订农村土地承包合同，该地块被征收产生的土地补偿款系对徐某某名下土地的补偿，应认定为徐某某的遗产。
    - 启示：农业经营用地（含菜园、打谷场等非口粮地）务必签订书面承包/流转合同并留存分配台账，明确是“按户承包”还是“按人分配、登记于个人名下”，写明面积、期限与调整规则，避免征收补偿归属长期悬空。
  - [拖欠款项] 2022年6月案涉土地被征收后，因徐某某家庭人员内部就该款项分配未达成一致意见，被告（村股份经济合作社）未向原告发放土地补偿款。 → 法院认为，被告作为农村集体经济组织，可以依照法律规定的民主议定程序，决定在本集体经济组织内部分配已经收到的土地补偿费；在徐某某的合法继承人未对遗产作出分割前，全部合法继承人对遗产属于共同共有，原告主张被告向其发放全部土地补偿款于法无据，应与其他合法继承人确定继承份额后再行主张权利。
    - 启示：合同中应预先约定款项的收款主体、分配条件与内部争议处理机制（如分配方案表决、指定共同收款人或提存），避免因收款人内部纠纷导致款项被扣留、错过主张时机。
  - [其他] 上诉人主张土地补偿款应按家庭为单位发放，并提交《常住人口登记表》《珠海街道办事处灵山湾路西延工程土地征用补偿协议》等证据，但被上诉人认为与本案无关。 → 法院依《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第九十条认定：上诉人主张案涉地块土地补偿款应按家庭为单位发放，但其一审提交的证据及二审提交的补偿协议均无法证明其主张，应由负有举证证明责任的当事人承担不利后果。
    - 启示：签约与履约阶段应同步固定书面证据（合同、分配方案、村民会议记录、收付款凭证），并在争议发生前明确约定举证责任与关键事实的确认方式，否则主张难以被采信。
- 原文摘录：案涉菜园地0.07亩，系分配给徐某某个人的，并不是以家庭承包方式承包，并非系三十年不变的承包地。双方亦未签订农村土地承包合同……案涉土地未办理登记且未签订农村土地承包合同……该部分土地补偿款应系徐某某的遗产。
